ChatGPT에서 o3를 직접 골라 쓰던 유료 사용자라면 8월 26일 전에 자주 쓰는 대화와 프롬프트를 한 번 점검하는 게 좋다. OpenAI가 ChatGPT 안의 o3를 종료한다고 공식 릴리스 노트에 안내했다. API의 o3까지 없어지는 것은 아니며, 무료 사용자가 따로 할 일도 거의 없다.

## 누가 영향을 받나

| 사용자 | 8월 26일 이후 | 지금 할 일 |
|---|---|---|
| 무료 사용자 | 원래 o3 선택 불가 | 별도 조치 없음 |
| Plus·Pro 사용자 | 모델 목록에서 o3 제거 | 자주 쓰는 대화 테스트 |
| 맞춤 GPT 제작자 | 연결 모델이 바뀔 수 있음 | 지침과 결과를 새 모델로 재검수 |
| API 사용자 | 이번 ChatGPT 종료와 별개 | API 공지와 별도 확인 |

기존 대화가 통째로 삭제되는 건 아니다. 다만 o3에 맞춰 만든 프롬프트는 다른 모델에서 결과가 달라질 수 있다. 긴 자료, 조건 비교, 숫자 계산을 시키던 대화라면 특히 그렇다.

## 10분 점검 방법

모든 대화를 저장할 필요는 없다. 최근 한 달 동안 o3를 선택한 대화 중 다시 쓸 것만 고르면 된다.

1. 대화 목록에서 업무·공부·반복 작업에 쓰던 o3 대화를 찾는다.
2. 답변 중 재사용할 프롬프트와 참고 파일을 별도 문서에 복사한다.
3. 새 모델에서 같은 입력을 한 번 실행한다.
4. 결과가 달라진 부분을 `추론 과정`, `형식`, `숫자`, `누락 정보`로 나눠 확인한다.

프롬프트는 이렇게 바꿔 적으면 재현하기 쉽다. 모델 이름보다 완료 조건을 남기는 게 핵심이다.

```text
아래 자료를 바탕으로 팀장 보고용 1쪽 요약을 작성해줘.
조건:
- 확인된 사실과 추정 내용을 분리할 것
- 숫자는 원문과 한 번 대조할 것
- 핵심 리스크 3개와 추가 확인 질문 3개를 표로 제시할 것
- 자료에 없는 내용은 추측하지 말고 '확인 필요'라고 표시할 것
```

## 내가 특히 확인할 부분

o3가 잘하던 문제 풀이와 복잡한 비교를 새 모델에 그대로 맡기고 “비슷하겠지”라고 넘기면 곤란하다. 답변의 말투보다 누락이나 숫자 오류가 더 늦게 발견된다. 계약 금액, 일정, 세금은 원문과 대조해야 한다.

또 하나의 함정은 맞춤 GPT다. o3를 기본 모델로 지정했다면 모델을 바꾼 뒤 테스트 질문 3개를 던져보자. 답변 형식, 금지사항 준수, 파일 인용 여부를 체크하면 된다.

이번 변경의 요점은 대화 백업보다 사용 습관 백업이다. o3를 쓰던 이유와 좋은 결과가 나왔던 입력 조건을 남겨두면 모델이 바뀌어도 업무 흐름을 이어갈 수 있다. 세부 일정은 [OpenAI ChatGPT 릴리스 노트](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)에서 확인할 수 있다.
