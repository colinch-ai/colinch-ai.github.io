![ChatGPT에 문서와 링크를 넣어 업무용 대시보드를 만드는 모습](/assets/images/chatgpt-sites-no-code-dashboard.png)

ChatGPT Sites는 코드를 쓰지 않고도 파일·링크·조건을 넣어 대시보드나 간단한 웹페이지를 만드는 기능이다. OpenAI 릴리스 노트 기준으로 2026년 8월 9일 현재 공개 베타가 진행 중이며, 결과를 미리 본 뒤 URL로 공유할 수 있다. 개발자가 아닌 사람에게는 “웹사이트를 만든다”보다 “자료를 읽히는 화면으로 묶는다”는 용도로 접근하는 편이 쉽다.

## 무엇을 만들면 좋은가

| 목적 | 넣을 자료 | 결과물 예시 |
|---|---|---|
| 주간 업무 공유 | 회의 메모, 일정표 | 진행률 대시보드 |
| 행사 안내 | 일정, 장소 링크, FAQ | 한 페이지 안내 사이트 |
| 공부 정리 | PDF, 참고 링크 | 주제별 학습 허브 |

처음부터 회사 홈페이지처럼 만들지 말고, 자료가 적고 다시 고치기 쉬운 프로젝트 현황판부터 시험하는 편이 낫다.

## 실제로 만드는 순서

ChatGPT 웹에서 Work를 열고, Sites가 보이면 새 작업을 시작한다. 공개 베타는 Pro·Pro Lite·Edu 사용자부터 제공되며 Plus 사용자는 순차 확대 중이다. Free·Go 요금제에는 제공되지 않고, 일부 지역은 공개 게시가 제한될 수 있다.

자료를 올리거나 링크를 붙인 뒤 아래처럼 지시한다.

```text
첨부한 회의 메모와 일정 링크를 바탕으로 팀 프로젝트 현황 사이트를 만들어줘.
완료·진행 중·확인 필요를 카드로 나누고, 일정은 날짜순으로 보여줘.
원문에 없는 내용은 추측하지 말고 '확인 필요'로 표시해줘.
모바일에서도 읽기 쉽게 만들고, 공개하기 전 수정할 수 있는 미리보기로 남겨줘.
```

첫 결과가 나오면 “카드마다 근거 문서 링크를 붙여줘”, “지난 일정은 접어줘”처럼 한 번에 한 가지씩 수정한다. 핵심은 멋진 문장보다 누가 언제 무엇을 봐야 하는지 정하는 데 있다.

## 공유 전 확인할 점

Sites는 자료를 화면으로 바꿔주는 도구이지, 사실관계를 검수해주는 도구는 아니다. 날짜·금액·담당자 이름을 원문과 대조하고 개인정보가 든 파일은 넣지 않는다. 공개 URL 전에는 비공개 미리보기에서 링크와 모바일 화면을 직접 눌러본다.

| 확인 항목 | 이유 |
|---|---|
| 공개 범위 | 내부 문서가 URL로 노출될 수 있음 |
| 출처 링크 | AI가 만든 설명의 근거 확인 |
| 모바일 화면 | 표와 버튼이 잘리는지 확인 |
| 최신 날짜 | 오래된 회의 자료가 섞이지 않았는지 확인 |

이번 기능의 장점은 코딩 지식보다 자료 구조와 지시문에 집중할 수 있다는 점이다. 복잡한 회원가입·결제·실시간 데이터 연결은 Sites만으로 끝내기 어렵다. 가벼운 안내 페이지나 업무 허브부터 만들어 보면 된다.
