Claude Workbench 레거시를 써왔다면 오늘 안에 저장 자료를 내보내야 한다. Anthropic은 2026년 8월 17일 기존 Workbench를 종료한다고 안내했다. 저장한 프롬프트, 실행 결과, 평가 기록이 새 화면으로 자동 이동하지 않는다.

그냥 Claude 채팅만 써온 사람은 해당되지 않는다. Claude Console에서 예전에 프롬프트를 저장하거나 여러 답변을 비교해본 사람이라면 확인할 필요가 있다.

## 지금 해야 할 일

Claude Console의 Workbench 레거시 화면에 들어가 상단 배너나 조직 설정의 Export를 찾는다. 내보낼 항목은 아래처럼 고르면 된다.

| 자료 | 백업할 이유 |
|---|---|
| 저장 프롬프트·변수 | 반복 업무용 지시문을 다시 만들지 않기 위해 |
| 모델 실행 결과 | 어떤 프롬프트가 잘 됐는지 비교하기 위해 |
| 평가 기록 | 팀에서 테스트한 기준을 남기기 위해 |
| 업로드 파일 | 실행 결과와 함께 참고한 원본을 보관하기 위해 |

Export를 누르면 자료가 준비된 뒤 이메일로 내려받을 수 있다. 업로드 파일까지 넣으면 용량이 커질 수 있으니 회사 컴퓨터가 아니라도 보관 위치를 정해두는 게 좋다. 다운로드한 JSON 파일은 메모장으로 열기보다 Google Drive나 별도 폴더에 원본 그대로 보관한다.

## 새 Workbench는 무엇이 다른가

새 Workbench는 프롬프트를 저장하는 작업장이 아니다. Claude 모델과 API(다른 서비스에서 Claude를 호출하는 연결 방식)를 시험하고, 입력과 결과를 확인한 뒤 코드 형태로 내보내는 간단한 테스트 화면에 가깝다.

| 구분 | 레거시 Workbench | 새 Workbench |
|---|---|---|
| 프롬프트 저장 | 가능 | 지원하지 않음 |
| 실행 기록·평가 | 저장 가능 | 저장하지 않음 |
| 주된 용도 | 프롬프트를 쌓고 비교 | 한 번 테스트하고 코드 확인 |
| 비개발자 활용 | 업무용 프롬프트 보관 | 문장 실험·결과 비교 |

그래서 새 화면을 개인 프롬프트 창고처럼 쓰면 안 된다. 앞으로 반복해서 쓸 지시문은 Notion, Google Docs, 메모 앱 중 한 곳에 직접 모아두는 편이 안전하다. 프롬프트마다 “목적·입력 자료·원하는 출력 형식·검토 기준” 네 줄을 붙여두면 나중에 Claude가 바뀌어도 재사용하기 쉽다.

## 백업할 때 놓치기 쉬운 점

6월 16일 이후 만든 계정은 레거시 Workbench에 접근할 수 없을 수 있다. 화면이 보이지 않는다고 자료가 삭제됐다고 단정할 필요는 없지만, 팀 계정 관리자에게 확인해야 한다. 또 새 Workbench에는 레거시 자료를 불러오는 기능이 없다.

내가 권하는 최소 백업 단위는 프롬프트만 따로 복사하는 것이 아니라, 실제 입력 예시와 마음에 들었던 답변 한 개를 함께 저장하는 방식이다. 프롬프트 문장만 남기면 어떤 상황에서 잘 작동했는지 알기 어렵다.

핵심은 간단하다. 오늘 Claude Workbench 레거시에서 Export를 실행하고, 반복 프롬프트는 별도 문서로 옮긴다. 새 Workbench는 저장소가 아니라 일회성 테스트 도구로 생각하면 헷갈리지 않는다.
