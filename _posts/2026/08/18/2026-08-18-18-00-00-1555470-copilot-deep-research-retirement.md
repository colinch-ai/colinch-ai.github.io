Copilot Deep Research가 오늘(2026년 8월 18일) 소비자용 Copilot 앱에서 종료됐다. 기존 보고서는 사라지지 않지만, 새 보고서를 같은 방식으로 만들려면 Microsoft 365 Premium의 Researcher를 써야 한다. Personal·Family 사용자는 예전 보고서를 채팅 기록에서 열 수 있으니 중요한 자료는 Word로 저장해두는 편이 안전하다.

## 무엇이 바뀌었나

Deep Research는 질문 하나로 여러 웹 자료를 찾아 출처가 붙은 보고서를 만드는 기능이었다. Microsoft 공식 문서 기준으로 Researcher는 웹뿐 아니라 권한이 있는 메일, 파일, 회의, 채팅까지 함께 살펴본다.

| 상황 | 선택지 | 현실적인 판단 |
|---|---|---|
| 예전에 만든 보고서 확인 | Copilot 채팅 기록 | 필요한 자료부터 Word로 저장 |
| 새 심층 보고서 작성 | Researcher | Microsoft 365 Premium 또는 회사용 Copilot 라이선스 필요 |
| 짧은 검색·요약 | 일반 Copilot | 여러 출처 비교는 직접 해야 함 |
| 비용을 늘리고 싶지 않음 | 검색 AI + 일반 챗봇 조합 | 출처 확인 단계를 반드시 추가 |

## 무료 사용자가 이어가는 조사 방법

한 도구로 전부 해결하려 하기보다 검색과 정리를 나눠 쓰는 편이 낫다.

1. 검색 AI에 “2024~2026년 국내 자료만 사용하고, 기관명·발표일·원문 링크를 표로 정리해줘”처럼 조건을 붙인다.
2. 나온 출처 중 정부·기업·연구기관 원문을 3개 이상 직접 연다.
3. 일반 Copilot이나 ChatGPT에 원문 링크 또는 핵심 문장을 넣고 비교표를 만든다.
4. 보고서에 넣기 전 숫자, 날짜, 전망과 사실을 따로 표시한다.

복사해서 쓸 프롬프트는 이 정도면 충분하다.

```text
아래 자료만 근거로 보고서를 작성해줘.
사실과 전망을 구분하고, 숫자마다 출처와 발표일을 붙여줘.
자료에 없는 내용은 추측하지 말고 '확인 필요'라고 표시해줘.
마지막에는 내가 추가로 확인할 질문 3개를 적어줘.
```

## Premium으로 바꿀 필요가 있을까

회사에서 Microsoft 365 파일과 메일을 매일 다루고, 월 2~3회 이상 보고서를 만든다면 Researcher가 시간을 줄일 수 있다. 한 달에 한두 번 비교 조사만 한다면 구독료를 늘리기보다 검색 결과를 직접 검증하는 편이 낫다. 출처 링크가 있어도 내용까지 자동으로 맞는 것은 아니다.

이번 변화의 핵심은 무료 도구에서 유료 조사 에이전트로 역할이 이동했다는 점이다. 기존 보고서를 보관하고, 앞으로는 “검색 → 원문 확인 → AI 정리” 세 단계를 습관으로 만들면 된다.
