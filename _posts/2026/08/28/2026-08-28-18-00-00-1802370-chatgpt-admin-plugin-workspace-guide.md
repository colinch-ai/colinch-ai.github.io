ChatGPT를 팀에서 쓰기 시작하면 어려운 건 질문을 잘 만드는 일이 아니다. 누가 얼마나 쓰는지, 퇴사자의 접근 권한이 남아 있는지, 사용량 한도를 어디서 바꾸는지가 더 번거롭다. OpenAI가 2026년 8월 25일 공개한 ChatGPT Admin 플러그인은 이 관리 작업을 대화창 안으로 가져온 기능이다.

## Admin 플러그인으로 할 수 있는 일

OpenAI 공식 설명에 따르면 관리자는 ChatGPT Work와 Codex의 활동·크레딧 사용량을 확인하고, 멤버와 그룹을 바꾸고, 역할별 기능·모델 접근 권한을 점검할 수 있다. 사용 한도나 지출 요청을 검토한 뒤 승인·거부하는 작업도 지원한다.

| 관리 상황 | 대화로 확인할 내용 | 바로 이어 할 일 |
|---|---|---|
| 사용량 점검 | 이번 달 사용량이 많은 팀과 한도에 가까운 사람 | 교육이 필요한 팀을 골라 안내 |
| 입·퇴사 처리 | 특정 멤버의 그룹과 현재 권한 | 그룹 변경 또는 접근 제거 |
| 권한 문의 | 왜 특정 모델이나 기능이 보이지 않는지 | 역할별 접근 설정 확인 |
| 비용 요청 | 요청자의 최근 사용량과 한도 | 승인하거나 사유를 남겨 거부 |

핵심은 “보고서 만들어줘”에서 끝나지 않는다는 점이다. 권한이 허용된 범위에서 상태를 확인하고, 지원되는 변경을 요청한 뒤 결과까지 확인한다. 관리자 권한을 새로 만들어주는 기능도 아니다.

## 비개발자 관리자가 써볼 질문

설치 후에는 실제 운영 질문부터 던지는 편이 낫다.

```text
이번 달 ChatGPT Work 사용량을 팀별로 정리해줘.
크레딧 한도에 80% 이상 도달한 멤버와 그룹을 표로 보여주고,
지난달보다 사용량이 크게 늘어난 이유를 확인할 수 있는 후속 질문도 제안해줘.
```

```text
퇴사 예정자 김OO의 현재 그룹, 모델 접근 권한, 진행 중인 사용량 요청을 확인해줘.
변경하기 전에 제거될 권한과 영향 범위를 먼저 보여줘.
```

“변경 전에 보여줘”를 붙이는 게 좋다. 멤버 제거와 권한 변경은 담당자가 최종 확인해야 한다.

## 설치 전에 확인할 점

설정에서 플러그인을 활성화한 뒤 웹이나 데스크톱 앱의 Plugins 디렉터리에서 설치한다. 개인 무료 계정용 기능은 아니므로 ChatGPT Work 또는 Codex의 관리자 권한을 확인해야 한다.

모든 사내 시스템을 조작하지는 않는다. 지원되는 작업만 처리하며 실제 권한과 승인 정책을 따른다. 사용량 기준과 권한 변경 승인자를 미리 정해두면 안전하다.

Admin 플러그인은 팀 관리자의 사용량·권한·비용 점검을 대화로 바꾸는 도구다. 소규모 팀도 매주 점검 질문을 정해두면 효과를 확인하기 쉽다.
