이 그림에서 볼 것은 AI가 답변만 만드는 게 아니라, 웹사이트가 제공하는 작업 도구를 찾아 실제 화면 흐름에 연결한다는 점이다.

ChatGPT가 웹페이지를 읽어주는 수준에서 한 단계 더 나아갔다. OpenAI는 2026년 8월 31일 릴리스 노트에서 데스크톱 앱의 내장 브라우저가 웹사이트가 직접 제공하는 도구를 찾아 쓸 수 있다고 안내했다. 예를 들어 지원 티켓을 확인하거나, 사이트의 검색·문의 기능을 이용해 작업 초안을 만들 수 있다. 다만 모든 웹사이트에서 되는 기능은 아니다.

## 실제로 어디에 쓰나

현실적인 용도는 ‘반복 입력 전 준비’다. 결제보다 여러 페이지의 정보를 모아 문의 내용을 만들거나 예약 후보를 정리하는 데 잘 맞는다.

| 상황 | ChatGPT에 맡길 일 | 사람이 확인할 일 |
|---|---|---|
| 고객센터 문의 | 주문 정보와 정책을 읽고 문의 초안 작성 | 개인정보·환불 사유 확인 후 전송 |
| 병원·식당 예약 | 가능한 시간과 조건 비교 | 날짜, 인원, 최종 예약 버튼 |
| 온라인 신청 | 페이지 항목 설명과 입력값 초안 | 주민번호·결제·제출 전 검토 |

사용 흐름은 간단하다.

1. ChatGPT 데스크톱 앱에서 지원되는 모델과 계정으로 로그인한다.
2. 작업할 웹사이트를 내장 브라우저로 연다.
3. 주소창의 도구 표시를 눌러 해당 페이지가 제공하는 기능을 확인한다.
4. “이 페이지에서 가능한 예약 시간을 표로 정리하고, 조건이 맞는 선택지만 보여줘. 결제와 제출은 하지 마.”처럼 범위를 정한다.
5. ChatGPT가 만든 결과를 확인한 뒤, 전송·예약·결제는 직접 승인한다.

복사해서 쓸 프롬프트는 이 정도면 충분하다.

```text
이 웹사이트에서 내가 할 수 있는 작업을 찾아줘.
목표는 [문의/예약/신청] 준비다.
내 조건은 [날짜, 예산, 지역, 인원]이다.
개인정보 입력, 결제, 최종 제출은 하지 말고
가능한 선택지와 확인이 필요한 항목만 표로 정리해줘.
```

처음엔 자동화가 알아서 끝내주는 기능이라고 생각했는데, 판단 지점은 여전히 사람 쪽에 남는다. 사이트가 도구를 제공하지 않으면 일반 웹 검색과 큰 차이가 없고, 페이지가 바뀌면 AI가 항목을 잘못 읽을 수도 있다. 로그인 상태의 메일, 병원, 금융 사이트에는 민감한 내용을 그대로 입력하지 않는 편이 안전하다.

이번 업데이트의 핵심은 ‘버튼 하나로 모든 일을 시킨다’가 아니다. 반복 작업의 초안을 줄이고 마지막 결정만 사람이 맡는 구조가 만들어졌다는 점이다. 지원 여부는 계정·모델·웹사이트에 따라 다르므로 주소창에 도구가 보이는지부터 확인하면 된다.
