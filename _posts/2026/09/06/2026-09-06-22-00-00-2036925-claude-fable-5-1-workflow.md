Claude Fable 5.1은 짧은 질문보다 긴 문서를 읽고 근거와 실행 순서까지 만드는 일에 잘 맞는다. Anthropic은 2026년 9월 1일 이 모델을 공개했고, 입력 캐시 읽기 비용을 낮춰 일반 작업은 Fable 5보다 약 25%, 에이전트 작업은 최대 약 45% 저렴해질 수 있다고 설명했다. 다만 API처럼 토큰으로 과금되는 작업 기준이다.

그림에서 볼 부분은 화면 속 문서가 단순 요약으로 끝나지 않고 요점과 체크리스트로 바뀌는 흐름이다.

## 이번 업데이트에서 체감할 부분

Fable 5.1과 Mythos 5.1은 같은 모델이지만 안전장치 수준이 다르다. Fable 5.1은 일반 사용자가 접근할 수 있고, Mythos 5.1은 검증된 파트너에게만 열려 있다.

| 확인할 점 | Fable 5.1에서 달라진 내용 | 실제 의미 |
|---|---|---|
| 긴 작업 | 여러 단계 문제 해결과 문서 작업 강화 | 보고서·회의자료를 한 번에 구조화하기 좋다 |
| 비용 | 캐시 읽기 가격 인하 | 같은 자료를 반복 참조하는 작업에 유리하다 |
| 안전장치 | 정상 요청을 잘못 막는 경우를 줄임 | 업무 질문이 중간에 끊길 가능성이 낮아졌다 |

## 비개발자가 쓰는 15분 문서 정리법

회의록, 경쟁사 자료, 정책 문서처럼 길고 산만한 파일을 Claude에 올린 뒤 아래 프롬프트를 그대로 붙여넣어봤다.

```text
이 문서를 다음 형식으로 정리해줘.
1. 핵심 결론 3개
2. 숫자와 날짜가 포함된 근거 표
3. 내가 이번 주에 해야 할 일 5개
4. 문서만으로 확정할 수 없는 내용
각 항목에 해당 페이지나 문단을 함께 표시하고, 추측은 추측이라고 써줘.
```

“요약해줘”라고만 했을 때보다 결과를 검증하기 쉬웠다. 마지막 줄을 빼면 문서에 없는 의도나 원인을 덧붙이는 경우가 있었다. 30쪽 자료라면 `핵심 주장 → 근거 확인 → 실행 목록` 순서로 나눠 요청하는 편이 안정적이다.

보고서로 바꿀 때는 “위 정리만 사용해서 제목, 현재 상황, 선택지 2개, 추천안, 결정이 필요한 질문 순서의 1쪽 초안을 써줘. 새로운 사실은 추가하지 말고 불확실한 부분은 [확인 필요]로 표시해줘”라고 이어서 요청하면 된다.

## 사용 전에 알아둘 한계

Fable 5.1이 더 똑똑해졌다는 발표와 내 문서에서 항상 맞는다는 말은 다르다. 회사 내부 숫자, 계약 조건, 인사 정보는 업로드 전에 보안 정책을 확인해야 한다. Anthropic의 기업용 보안 체계도 단계적으로 제공될 예정이다.

“에이전트 작업 비용 최대 45% 절감”은 Claude 구독료가 내려간다는 뜻이 아니다. 같은 자료를 반복 참조하는 API 작업에서 효과가 커진다는 의미이며, 실제 사용량은 파일 크기와 대화 횟수에 따라 달라진다.

짧게 정리하면, Claude Fable 5.1은 새 모델 이름만 확인하고 끝낼 업데이트가 아니다. 긴 자료를 근거와 함께 정리하거나, 초안을 여러 단계로 다듬는 사람이라면 위 프롬프트부터 시험해볼 만하다. 반대로 민감한 사내 문서를 바로 올리거나 답변을 최종본으로 믿는 방식은 여전히 위험하다.
