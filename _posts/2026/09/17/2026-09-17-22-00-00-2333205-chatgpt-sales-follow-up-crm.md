영업 상담이 끝난 뒤 후속메일과 CRM 기록을 매번 직접 쓰는 담당자라면 ChatGPT·Claude·Gemini의 무료 기능만으로도 초안 자동화를 시작할 수 있다. 상담 원문이 짧고 하루 5건 안팎이면 무료로 충분하다. 여러 녹취 파일을 계속 올리거나 회사 고객정보를 다뤄야 한다면 개인 유료 계정보다 회사가 승인한 업무용 환경을 먼저 확인해야 한다.

## 결과물은 메일 한 통이 아니라 두 개다

AI에게 “메일 써줘”라고만 하면 그럴듯한 문장이 나오지만 CRM에 다시 옮겨 적는 일이 남는다. 입력부터 아래 두 결과를 요구해야 반복 업무가 줄어든다.

| 결과물 | 반드시 남길 항목 | 사람이 확인할 부분 |
|---|---|---|
| 고객 후속메일 | 고객의 질문, 합의된 내용, 다음 행동, 날짜 | 가격·납기·할인 약속 |
| CRM 기록 | 단계, 관심 제품, 예산 범위, 결정권자, 다음 연락일 | 원문에 없는 추정값 |

아래 프롬프트에서 대괄호 안 정보만 바꿔 쓴다. 실제 상담 기록을 붙여넣을 때 이름·전화번호·이메일·회사 내부 가격표는 익명화한다.

```text
너는 B2B 영업 담당자의 기록 보조자다.
아래 상담 기록에 실제로 나온 내용만 사용해 결과를 만들어라.
없는 정보는 추측하지 말고 "확인 필요"라고 써라.

상담 기록:
[익명화한 상담 원문]

출력 형식:
1) 고객에게 보낼 5문장 이내 후속메일 초안
2) CRM 입력표: 고객 문제 / 관심 제품 / 예산 / 결정권자 / 이의사항 / 다음 행동 / 다음 연락일
3) 원문에서 근거가 있는 문장을 항목별로 짧게 인용
4) 담당자가 보내기 전에 확인할 숫자와 약속을 체크리스트로 제시
```

메일 초안만 받는 것보다 근거 문장을 같이 받는 편이 검수가 쉽다. 상담에서 “다음 주 초”라고만 말했는데 AI가 임의로 월요일을 넣는지, 할인 가능성을 확정 가격처럼 바꾸는지가 대표적인 실패 지점이다.

## 무료와 유료의 경계는 모델 이름보다 입력량이다

2026년 9월 17일 확인 기준으로 ChatGPT는 무료 계정에서도 파일 업로드가 가능하지만 사용량 제한이 있고, OpenAI 도움말은 무료 사용자의 파일 업로드를 하루 3개로 안내한다. 파일 하나의 크기와 문서 토큰 제한도 별도로 있다. 짧은 상담 메모를 복사해 쓰는 단계라면 결제 이유가 약하다.

| 상황 | 무료로 시작 | 유료 전환을 검토할 때 |
|---|---|---|
| 하루 1~5건 텍스트 상담 | ChatGPT·Claude·Gemini 중 익숙한 도구 하나 | 답변 품질 차이를 샘플 10건으로 확인한 뒤 결정 |
| 녹취·PDF·CSV를 반복 업로드 | 파일 수를 줄이고 핵심 구간만 추출 | 업로드 한도에 주 2회 이상 막히거나 여러 파일 비교가 필요할 때 |
| 팀이 같은 양식을 사용 | 프롬프트를 문서로 공유 | 권한 관리·감사 기록·업무용 데이터 보호가 필요할 때 |

유료 구독이 정확성을 보장하는 것은 아니다. 단지 한도와 작업 편의가 늘어나는 경우가 많다. ChatGPT의 개인용 데이터 설정은 `Settings → Data Controls → Improve the model for everyone`에서 끌 수 있지만, 회사 정책을 대신하지 않는다. Gemini도 Keep Activity와 임시 채팅 설정에 따라 처리 방식이 달라지며, Google은 일부 대화가 사람 검토 대상이 될 수 있다고 안내한다. 고객정보를 그대로 넣어도 된다는 뜻으로 해석하면 안 된다.

## 발송 전 60초 검수표

- [ ] 고객명·회사명·연락처가 실제 수신자와 일치하는가
- [ ] 가격, 할인, 납기, 환불 조건이 상담 원문이나 공식 문서에 있는가
- [ ] CRM의 다음 연락일이 AI의 추측이 아닌 합의된 날짜인가
- [ ] “확인 필요” 항목을 담당자가 채웠는가
- [ ] AI가 만든 문장을 그대로 자동 발송하지 않았는가

검증 결과는 `메일 초안 / CRM 표 / 근거 문장 / 확인 필요` 네 덩어리로 저장하면 된다. 영업팀이 하루 10건 이하를 처리한다면 이 복사·검수 흐름부터 시험하고, 업로드 한도나 팀 관리가 실제 병목일 때만 유료 플랜을 비교하는 편이 비용과 전환 위험을 함께 줄인다.
