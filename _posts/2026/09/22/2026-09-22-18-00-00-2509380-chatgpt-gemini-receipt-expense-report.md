영수증을 매주 10~30장씩 입력하는 총무라면 ChatGPT 무료 기능으로 소량 테스트를 시작하고, 반복량이 늘 때만 유료 플랜이나 사내 승인 환경을 검토하는 편이 낫다. 반대로 주민등록번호, 카드번호, 거래처 계좌처럼 민감한 정보가 찍힌 원본을 개인 계정에 바로 올리는 방식은 이 글의 적용 대상이 아니다. 목표는 “AI가 회계 처리를 끝낸다”가 아니라, 사람이 확인할 수 있는 지출표 초안을 남기는 것이다.

그림에서 볼 것은 영수증 인식 자체보다 `추출 → 정책 확인 → 승인 여부`로 나뉜 흐름이다.

## 무료와 유료를 가르는 기준

| 상황 | 무료로 시작할 조건 | 유료·업무용 환경을 검토할 조건 |
|---|---|---|
| 처리량 | 주 3~10장, 한 번에 한 파일 | 매일 여러 장, 팀원이 공동 처리 |
| 결과물 | CSV 초안과 원본 대조 | 원장·감사 로그·권한 관리까지 필요 |
| 개인정보 | 가린 테스트 영수증 | 고객·직원 식별정보가 포함된 원본 |
| 비용 판단 | 누락 행과 재입력 시간을 기록 | 한 달 검수 시간이 구독료보다 큼 |

OpenAI의 파일 업로드 안내는 무료와 유료 모두 업로드를 지원하지만 무료 사용자는 하루 3개 파일로 제한될 수 있다고 설명한다. 플랜별 한도는 바뀔 수 있으므로 2026년 9월 22일 화면에서 확인해야 한다. ChatGPT의 Temporary Chat은 기록과 모델 개선 사용을 줄이는 선택지지만, 안전을 위해 최대 30일 사본이 보관될 수 있다. “무료니까 회사 자료를 넣어도 된다”는 뜻은 아니다.

Gemini도 활동 설정에 따라 처리 방식이 달라진다. Google은 Keep Activity를 끄면 향후 채팅이 모델 학습에 사용되지 않지만 72시간 보관될 수 있고 일부 연결 앱을 쓸 수 없다고 안내한다. 회사 정책이 있다면 개인 설정으로 우회하지 말고 승인된 계정과 저장 위치를 사용해야 한다.

## 복사해서 쓰는 지출표 프롬프트

아래 프롬프트에 익명화한 영수증 이미지 또는 텍스트를 넣는다. 실제 금액을 바꾸지 말고, 테스트라면 가상 영수증이라고 표시한다.

```text
너는 지출 입력 보조자다. 영수증에 보이는 내용만 추출하고 추측하지 마라.
다음 열의 Markdown 표를 만들어라: 날짜 | 상호 | 공급가액 | 부가세 | 합계 | 통화 | 분류 | 근거 위치 | 확인 상태.
읽을 수 없거나 영수증에 없는 값은 빈칸으로 두고 확인 상태를 “사람 확인”으로 써라.
분류는 식비·교통·소모품·접대·기타 중 하나만 제안하되, 근거가 없으면 기타로 둬라.
합계와 공급가액+부가세가 다르면 “금액 불일치”라고 표시하라.
마지막에 승인 전에 사람이 확인할 항목 3개를 적어라.
```

결과를 그대로 회계 원장에 붙이지 않는다. 날짜·상호·합계는 원본과 대조하고, 분류와 승인 여부는 회사 규정에 맞춰 사람이 바꾼다. n8n의 공개 Gemini 예시도 `Policy Rules`, `Ledger`, `Audit Log`를 분리하는 구조를 사용한다. 이 구분이 있어야 AI가 분류를 잘못해도 왜 승인했는지 추적할 수 있다.

## 10건으로 유료 전환을 검증하는 체크리스트

- [ ] 개인정보를 가린 테스트 영수증 10건을 준비했다.
- [ ] 추출값마다 원본에서 확인할 위치를 남겼다.
- [ ] 합계 오류, 날짜 누락, 중복 영수증 개수를 셌다.
- [ ] 사람이 수정한 행과 AI 초안 행을 구분했다.
- [ ] 10건 처리에 걸린 시간과 수동 입력 시간을 비교했다.
- [ ] 회사 계정·보관 기간·외부 전송 정책을 확인했다.

10건 중 1~2건만 고치면 무료 흐름을 유지해도 된다. 누락이 반복되거나 팀 공유·권한·감사 로그가 필요할 때 유료 전환을 검토한다. 유료 플랜이 정확도를 보장하는 것은 아니며, 가격보다 검수 비용과 데이터 정책이 먼저다.
