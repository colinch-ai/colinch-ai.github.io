하루에 비슷한 고객 문의가 10건 안팎 들어오는 지원 담당자라면 익명화한 문의 20건으로 ChatGPT·Claude·Gemini 중 익숙한 도구 하나를 무료 검증하는 선택이 유리하다. 단순 답변 초안보다 FAQ와 “사람에게 넘길 조건”을 함께 만들 때 효과가 측정된다. 결제·환불·장애처럼 책임이 큰 답변을 자동 발송하려는 경우에는 이 방식이 적용되지 않는다.

그림에서 볼 것은 챗봇 자체가 아니라 `문의 원문 → FAQ 초안 → 근거 확인 → 에스컬레이션`의 순서다.

## 무료와 유료를 가르는 기준

무료·유료 차이를 모델 이름만으로 고르면 판단이 흔들린다. 입력 파일 수, 대화 길이, 팀 공유, 보관 정책이 실제 병목인지 먼저 센다. OpenAI는 CSV·PDF 같은 파일 분석을 안내하지만 계정과 요금제에 따라 사용 가능한 기능이 달라질 수 있다. Anthropic도 Claude 사용량이 메시지 길이, 첨부 크기, 대화 길이, 도구 사용량에 따라 달라진다고 설명한다.

| 반복 업무 조건 | 무료로 검증할 선택 | 유료·업무용 환경을 검토할 조건 |
|---|---|---|
| 입력 | 이름·연락처를 지운 문의 20건 | 매일 여러 파일을 팀 단위로 처리 |
| 결과물 | FAQ 5개와 보류 질문 목록 | 권한, 공유, 승인 이력까지 필요 |
| 오류 비용 | 담당자가 전부 발송 전 확인 | SLA·환불·법무 문구가 포함됨 |
| 개인정보 | 가명·주문번호 일부 마스킹 | 회사 승인 계정과 보관 규칙이 있음 |

구독 전에는 같은 문의 10건을 세 도구에 나눠 넣고 `사실 오류`, `누락`, `사람에게 넘겨야 하는데 답한 경우`를 각각 센다. 오류가 줄지 않고 입력 한도만 늘어난다면 결제 근거가 약하다.

## 복사해서 쓰는 FAQ 생성 프롬프트

문의 원문을 붙여넣기 전에 고객명, 전화번호, 이메일, 주소, 전체 주문번호를 지운다. 그다음 아래 프롬프트를 ChatGPT·Claude·Gemini에 같은 조건으로 넣는다.

```text
너는 고객지원 문서 보조자다. 아래 문의 원문에 실제로 나온 사실만 사용하라.
없는 정책·가격·배송일은 추측하지 말고 “확인 필요”로 표시하라.

출력 형식:
1. 반복 질문을 최대 5개 주제로 묶고 대표 문의를 적어라.
2. 각 주제의 FAQ 답변은 3문장 이내로 작성하라.
3. 답변마다 근거가 된 문의 번호를 붙여라.
4. 환불, 개인정보, 장애, 법적 분쟁, 예외 요청은 에스컬레이션 조건으로 분리하라.
5. 원문에 없는 정보와 담당자가 확인할 질문을 별도 표로 만들어라.
6. 확정 답변처럼 쓰지 말고 “초안”이라고 표시하라.
결과: FAQ 표 → 에스컬레이션 표 → 확인 필요 목록
```

FAQ만 만들면 AI가 빈칸을 그럴듯하게 채운다. 근거 번호를 요구하면 “배송은 2일”처럼 원문에 없는 숫자가 섞였는지 바로 찾기 쉽다.

## 발송 전 검수표

- [ ] 답변의 가격·기한·환불 조건이 승인된 문서와 일치하는가
- [ ] 근거 문의에 없는 숫자와 정책을 AI가 추가하지 않았는가
- [ ] 예외·분쟁·장애 문의가 자동 답변 대상에서 빠졌는가
- [ ] 고객 식별정보와 주문번호가 결과물에 남지 않았는가
- [ ] FAQ 버전, 검수자, 확인 날짜를 기록했는가

개인정보 설정도 무료·유료 선택의 일부다. OpenAI는 소비자 서비스에서 데이터 제어와 임시 채팅을 제공하지만 계정 유형과 요금제에 따라 제어 범위가 다르다고 안내한다. Google은 Gemini Apps에서 업로드 콘텐츠와 대화가 처리될 수 있고, 일부 데이터가 사람 검토 대상이 될 수 있다고 설명한다. Anthropic도 민감한 금융·건강·자격 증명 정보를 소비자용 Claude에 넣지 말라고 권고한다. 따라서 회사 문의 원문은 익명화만으로 충분하다고 단정하지 말고 사내 승인 계정을 확인해야 한다.

처음에는 무료 계정과 가상 문의 20건으로 FAQ 5개를 만들고, 오류 유형을 표로 남긴다. 2주 동안 같은 작업을 반복했는데 파일 한도·팀 승인·보관 로그가 실제 시간을 잡아먹을 때만 유료 전환을 검토하면 된다. AI가 답변을 대신 책임지는 구조가 아니라, 반복되는 초안 작성만 줄이고 최종 판단은 담당자가 보유하는 구조다.
