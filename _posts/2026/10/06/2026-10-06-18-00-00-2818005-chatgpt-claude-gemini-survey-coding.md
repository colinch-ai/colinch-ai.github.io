설문 응답이 30~100건 정도이고 이름·연락처를 지운 상태라면 ChatGPT·Claude·Gemini 무료 기능으로 코드북 초안과 응답별 분류표를 만들 수 있다. 반대로 수천 건을 매달 처리하거나 원문 보관·팀 권한·감사 기록이 필요하면 개인 계정에 파일을 올리는 방식보다 승인된 리서치 도구나 업무용 환경을 검토해야 한다. AI에게 맡길 일은 “의견을 대신 판단하기”가 아니라 같은 기준으로 분류하고 사람이 다시 볼 행을 남기는 일이다.

## 요약문보다 코드표가 필요한 이유

“설문 결과를 요약해줘”라고 하면 대표 의견은 나오지만, 어떤 응답이 어떤 주제에 들어갔는지 추적하기 어렵다. 응답마다 `response_id`, 짧은 코드, 상위 테마, 근거 문장, 확신도, 사람 검토 여부를 고정하면 숫자를 세기 전부터 오류를 찾을 수 있다.

| 결과 열 | 쓰임 | AI가 추측하면 안 되는 것 |
|---|---|---|
| 응답 ID | 원문 재확인 | 새 ID 만들기 |
| 코드·테마 | 반복 이슈 묶기 | 응답에 없는 의도 |
| 근거 문장 | 분류 이유 확인 | 문장 바꿔 쓰기 |
| 재검토 사유 | 애매한 응답 보류 | 억지로 단일 분류 |

## 복사해서 쓰는 프롬프트

CSV에서 응답 ID와 답변만 남기고 개인정보를 제거한 뒤 사용한다.

```text
너는 설문 데이터 코딩 보조자다.
응답 원문에 있는 내용만 사용하고 의도·원인·감정을 추측하지 마라.
각 응답에 대해 아래 열을 표로 출력하라.
response_id | 1차 코드 | 상위 테마 | 근거 문장(원문 그대로) | 확신도(높음/중간/낮음) | 재검토 사유

같은 의미는 같은 코드로 묶되, 한 응답에 여러 주제가 있으면 복수 코드를 허용하라.
새 테마가 필요하면 기존 코드북에 없는 이유를 한 줄로 적어라.
근거 문장이 없거나 확신도가 낮은 행은 재검토 대상으로 표시하라.
마지막에 코드별 응답 수를 세되, 전체 응답 수와 합계가 맞는지 확인하라.
```

처음부터 1,000건을 넣지 말고 가상 또는 비식별 응답 20건으로 코드 정의가 일관적인지 본다. 실제 결과에서는 코드별 대표 문장 1~2개를 원문과 대조하고, 낮은 확신도 행만 사람이 다시 읽는 방식이 효율적이다. 검색 결과의 설문 분석 사례도 응답 ID와 원문 인용을 붙이고 일부 분류를 수동 검증하는 흐름을 권한다([AI Tools Guidebook 사례](https://aitoolsguidebook.com/en/articles/survey-analysis/)).

## 무료와 유료의 경계

| 상황 | 선택 | 판단 기준 |
|---|---|---|
| 일회성, 100건 안팎, 비식별 CSV | 무료 ChatGPT·Claude·Gemini | 코드표 형식과 누락 검수부터 확인 |
| 파일을 자주 올리고 긴 원문을 반복 처리 | 개인 유료 플랜 검토 | 업로드 한도와 문서 처리량이 실제 병목인가 |
| 고객 조사 원문, 팀 공유, 보관·권한 필요 | 회사 승인 도구 | 개인 구독이 아니라 데이터 처리 조건을 확인 |

OpenAI 공식 문서 기준으로 ChatGPT 파일 업로드는 무료·유료 플랜 모두 가능하지만 플랜별 한도가 다르고, 무료 사용자는 하루 3회 업로드 제한이 안내돼 있다([파일 업로드 FAQ](https://help.openai.com/en/articles/8555545-uploading-images-and-files-in-chatgpt)). Google Workspace의 Gemini는 조직용 환경에서 Workspace 파일을 기반 모델 학습에 사용하지 않는다고 안내하지만, 개인용 Gemini 앱의 데이터 정책은 별도다([Google Workspace 개인정보 안내](https://support.google.com/docs/answer/10381817?hl=en)). 서비스 이름보다 계정 유형과 회사 정책을 먼저 확인해야 하는 이유다.

## 발행 전 검수표

- [ ] 응답 ID가 원본 CSV와 일치하는가
- [ ] 근거 문장이 실제 응답의 일부인가
- [ ] `없음`과 `언급되지 않음`을 구분했는가
- [ ] 코드별 합계가 전체 응답 수와 맞는가
- [ ] 이름·이메일·연락처·자유 서술의 개인정보를 제거했는가
- [ ] AI 분류 결과를 최종 고객 인사이트로 바로 확정하지 않았는가

주관식 코딩의 성공 기준은 멋진 요약문이 아니다. 다른 사람이 원문을 열었을 때 왜 그 코드가 붙었는지 확인할 수 있고, 애매한 응답이 별도 큐에 남는가가 기준이다. 소량의 익명 데이터로 무료 도구를 시험한 뒤 업로드 한도, 협업, 보관 정책이 실제 문제로 확인될 때만 유료 전환을 판단하면 된다.
