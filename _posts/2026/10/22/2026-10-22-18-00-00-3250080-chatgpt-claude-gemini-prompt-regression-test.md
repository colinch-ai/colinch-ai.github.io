같은 업무 프롬프트를 매주 쓰는 마케터·기획자·운영 담당자라면, 새 모델을 무작정 유료 결제하기보다 5~10개의 고정 입력으로 ChatGPT·Claude·Gemini 결과를 비교하는 편이 낫다. 출력 형식, 사실 보존, 금지 표현처럼 확인 가능한 기준을 정하면 무료 계정으로도 시험할 수 있다. 반대로 원문에 개인정보가 있고 자동 발송까지 연결하려는 경우에는 개인 무료·유료 채팅이 아니라 회사가 승인한 환경을 검토해야 한다.

## “더 좋아졌나?”를 느낌으로 판단하지 않는다

프롬프트를 조금 고치거나 모델이 바뀌면 답변은 자연스럽게 달라진다. 문제는 문장이 좋아 보인다는 이유로 필수 항목 누락을 놓치는 데 있다. Anthropic 공식 평가 문서도 성공 기준을 수치화하고, 테스트 세트와 평가 기준을 분리해 확인하는 흐름을 제안한다. 여기서 말하는 회귀 테스트는 개발자만의 자동화가 아니라, 반복 업무의 표준 입력을 보관하고 이전 결과와 나란히 비교하는 간단한 검수표다.

| 검수 항목 | 통과 기준 예시 | 실패로 기록할 것 |
|---|---|---|
| 사실 보존 | 원문 날짜·금액·고유명사를 바꾸지 않음 | 숫자 임의 반올림, 없는 정보 추가 |
| 형식 | 지정한 열 7개를 모두 출력 | 표 대신 긴 문단, 열 누락 |
| 업무 규칙 | 불확실한 값은 `확인 필요`로 표시 | 추측으로 상태 확정 |
| 문체 | 500자 이내, 고객 발송 금지 문구 준수 | 과장 표현, 자동 발송 문장 |

## 복사해서 쓰는 회귀 테스트 프롬프트

아래 프롬프트에 실제 기밀 대신 가상 입력 5개를 넣고 세 도구에서 같은 순서로 실행한다.

```text
너는 [직무]의 반복 업무 검수 보조다.
입력에 실제로 적힌 내용만 사용하고 추측하지 마라.
결과를 다음 열의 Markdown 표로 출력하라:
입력 ID | 핵심 결과 | 근거 문장 | 누락 여부 | 형식 오류 | 확인 필요 | 최종 판정

규칙:
1. 날짜·금액·고유명사는 원문과 다르면 오류로 표시한다.
2. 근거가 없으면 빈칸 대신 “근거 없음”이라고 쓴다.
3. 자동 승인·발송·결제는 판정하지 말고 “사람 확인”으로 둔다.
4. 마지막에 오류 개수와 통과율을 계산하되, 계산 근거를 함께 보여라.
```

결과를 저장할 때는 모델 이름만 적지 말고 실행 날짜, 모델 표시명, 프롬프트 버전, 입력 ID를 같이 남긴다. ‘통과율 90%’도 전체 10건 중 9건인지, 형식만 맞은 것인지 구분해야 한다. 입력 5건 중 1건이라도 금액을 바꿨다면 금액 보존 기준은 실패로 처리하는 식으로 치명도별 기준을 따로 둔다.

## 무료와 유료의 경계

| 상황 | 선택 | 이유 |
|---|---|---|
| 가상 입력 5~10건, 주 1회 | 무료 플랜 | 프롬프트 형식과 검수표를 시험하기 충분하다 |
| 긴 파일 여러 개, 매일 반복 | 유료 검토 | 업로드·메시지·프로젝트 한도가 병목이 된다 |
| 고객정보·인사자료·계약 원문 | 승인된 업무용 환경 | 개인 플랜 결제가 곧 회사 데이터 보호를 뜻하지 않는다 |

확인 날짜는 2026년 10월 22일이다. OpenAI는 무료 플랜의 파일 업로드와 데이터 분석이 제한된다고 안내하고, 무료 사용자의 파일 업로드 횟수도 별도 제한으로 설명한다([ChatGPT 파일 업로드 안내](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)). Claude도 플랜뿐 아니라 메시지 길이·첨부 크기·대화 길이에 따라 사용량이 달라진다([Anthropic 사용량 안내](https://support.anthropic.com/en/articles/9797557-usage-limit-best-practices)). 가격보다 이 작업에서 중요한 것은 한도에 걸렸을 때 사람이 수동 검수로 되돌아갈 수 있는가다.

개인 계정에 원문을 넣기 전에는 이름·전화번호·이메일·계약번호를 가린다. ChatGPT는 데이터 학습 설정을 끌 수 있지만 대화 기록이 자동 삭제되는 것은 아니며, Gemini도 업로드 파일과 활동 처리 조건을 별도로 안내한다. 민감한 입력을 넣을 수 없다면 가상 데이터로 프롬프트 구조만 검증하고 실제 처리는 회사 정책에 맞춘다.

짧게 정리하면, 반복 프롬프트의 품질은 “어느 AI가 제일 똑똑한가”보다 고정 입력·명시 기준·실패 기록으로 판단해야 한다. 무료로 5건을 비교해 필수 오류가 없는지 확인하고, 파일량과 공유·권한 관리가 병목일 때만 유료 전환을 검토하면 된다.
