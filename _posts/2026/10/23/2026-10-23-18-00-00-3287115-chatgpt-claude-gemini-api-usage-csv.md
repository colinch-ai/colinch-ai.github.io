이 그림에서 볼 것은 AI가 비용을 “맞혀주는” 장면이 아니라, 원본 CSV의 합계와 사람이 확인할 예외 목록을 분리하는 흐름이다.

월말에 AI 사용량을 정리하는 운영 담당자라면 ChatGPT·Claude·Gemini 중 하나에 CSV를 넣어 **모델별 호출 수, 토큰, 실패 요청, 청구 금액 차이**를 표로 만들 수 있다. 월 1~2회, 비식별화된 작은 파일만 보는 개인이라면 무료 플랜으로 충분하다. 팀별 원본 로그나 고객 정보가 들어가고 반복 처리·권한 관리가 필요하면 개인 유료 결제로 바로 가기보다 회사용 정책과 보존 조건을 확인해야 한다.

## 이 업무에서 확인할 열

서비스마다 내보내기 열 이름은 다르다. `date`, `provider`, `model`, `input_tokens`, `output_tokens`, `status`, `latency_ms`, `cost_usd` 정도로 표준화하면 세 파일을 합치기 쉽다.

| 검수 항목 | 확인할 질문 | 결과물 |
|---|---|---|
| 비용 | CSV 합계와 청구서 금액이 다른가? | 차이 금액·원인 후보 |
| 사용량 | 특정 모델이나 팀이 갑자기 늘었나? | 일자·모델별 피벗표 |
| 실패 | 실패·재시도 요청이 비용에 포함됐나? | 실패 행 목록 |
| 개인정보 | 프롬프트 원문이나 이메일이 남아 있나? | 업로드 제외 열 |

비용은 모델 가격표를 AI가 추정하게 두지 말고, CSV의 `cost_usd`와 청구서 금액을 우선 비교해야 한다. 가격표가 없거나 캐시·배치·우선 처리 요금이 섞이면 토큰에 단가를 곱한 값은 추정치일 뿐이다.

## 복사해서 쓰는 검수 프롬프트

CSV를 올리기 전에 이름, 이메일, API 키, 프롬프트 원문을 제거한다. 아래 문장은 서비스가 달라도 같은 결과 구조를 요구하도록 만든다.

```text
너는 AI 사용량 정산 검수자다. 업로드한 CSV를 원본 행 기준으로만 분석하라.
1) 열 이름을 표준화하고, 숫자로 읽히지 않는 값은 별도 목록으로 분리하라.
2) provider·model·date별 호출 수, input_tokens, output_tokens, cost_usd를 합산하라.
3) status가 실패인 행, 중복 id, 음수 비용, 날짜 누락을 검수표로 출력하라.
4) CSV 비용 합계와 내가 입력한 청구 금액 [금액]의 차이를 계산하라.
5) 추정·가정·원본에서 직접 확인한 값을 구분하고, 결론마다 근거 행 수를 적어라.
계산에 사용한 코드나 수식을 보여주고, 원본에 없는 원인은 추측하지 마라.
```

AI 답변의 합계만 복사하지 말고, 결과 표의 행 수와 표본 3건을 원본과 대조한다. 특히 같은 요청을 재시도한 행을 “사용량 증가”로 잘못 세는 일이 흔하다.

## 무료와 유료의 경계

| 상황 | 선택 기준 |
|---|---|
| 한 달에 짧은 CSV 1~2개 | 무료로 샘플 20행을 먼저 검수 |
| 매주 여러 파일·차트 생성 | 파일·데이터 분석 한도를 확인한 뒤 개인 유료 검토 |
| 팀 원본 로그·관리자 권한 필요 | Business·Enterprise·조직용 Google Workspace 정책 우선 |
| 민감한 프롬프트 포함 | 원문 제거 또는 승인된 사내 환경만 사용 |

확인 날짜는 2026년 10월 23일이다. OpenAI는 무료·유료 플랜 모두 파일 업로드가 가능하지만 플랜별 한도와 설정이 다르다고 안내한다. CSV·스프레드시트 분석과 코드 기반 계산도 지원한다([파일 업로드 안내](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt), [데이터 분석 안내](https://help.openai.com/ko-kr/articles/8437071-data-analysis-with-chatgpt)). Anthropic은 Claude에서 CSV를 지원하고 채팅 파일은 파일당 30MB, 대화당 최대 20개라고 설명한다([문서 업로드 안내](https://support.anthropic.com/en/articles/8241126-what-kinds-of-documents-can-i-upload-to-claude-ai)). Gemini Apps는 스프레드시트 분석과 차트 생성을 제공하며, 한 프롬프트에 최대 10개 파일을 올릴 수 있고 상위 Google AI 요금제에서 더 높은 한도를 제공한다고 안내한다([Gemini 파일 분석 안내](https://support.google.com/gemini/answer/14903178?hl=ko)). 이 숫자는 계정·지역·시점에 따라 바뀔 수 있다.

개인용 ChatGPT의 파일은 설정에 따라 모델 개선에 사용될 수 있다는 안내가 있으므로, 회사 로그를 그대로 올려도 된다는 뜻으로 해석하면 안 된다([OpenAI 소비자 데이터 FAQ](https://help.openai.com/en/articles/7039943-how-chatgpt-uses-data)). 유료라는 이유만으로 모든 보안 요구를 충족하지도 않는다.

## 짧은 실행 체크리스트

- [ ] 원문·키·이메일을 제거하고 익명 ID로 바꿨다.
- [ ] 세 서비스의 열 이름과 통화 단위를 맞췄다.
- [ ] 비용 합계와 청구서 금액의 기준 기간이 같다.
- [ ] 실패·재시도·중복 행을 따로 표시했다.
- [ ] AI가 만든 합계를 원본 행 수와 표본으로 다시 확인했다.

이 방법의 목적은 가장 싼 AI를 고르는 것이 아니다. 반복되는 정산 작업에서 사람이 다시 볼 행을 줄이고, 무료 한도로 충분한지 유료·조직용 환경이 필요한지 근거를 남기는 데 있다.
