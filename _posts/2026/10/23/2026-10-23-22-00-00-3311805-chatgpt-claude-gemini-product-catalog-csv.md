이 그림에서 볼 것은 상품 설명을 예쁘게 쓰는 장면이 아니라, 등록 전에 사람이 확인할 누락 행을 표로 좁히는 흐름이다.

상품을 여러 채널에 올리는 쇼핑몰 운영자라면 ChatGPT·Claude·Gemini 무료 기능으로 카탈로그 CSV의 필수값과 옵션 불일치를 점검할 수 있다. 상품 10~30개를 가끔 등록하는 경우엔 무료로 충분하다. 반대로 고객 식별정보가 들어간 주문 파일을 함께 올리거나 AI 결과를 그대로 판매 페이지에 반영하려는 경우에는 이 방법이 맞지 않는다. AI는 등록 승인자가 아니라 검수 보조자다.

## 요약문보다 누락표가 필요한 이유

카탈로그에는 상품명, 판매가, 재고뿐 아니라 옵션 조합, 배송비, 교환·반품 조건, 필수 고지처럼 서로 다른 성격의 값이 섞인다. “상품 정보를 정리해줘”라고 하면 읽기 좋은 설명만 나오고 빈칸의 위험도는 드러나지 않는다. 카페24·광고 플랫폼 등 일부 업로드 양식도 CSV 인코딩과 열 구조를 요구하므로, 문장 품질보다 행 단위 검수가 먼저다. [카탈로그 CSV 업로드 안내](https://adure.cafe24.com/uploads/adure/1769570832_%EB%8B%B9%EA%B7%BC_%EC%A0%84%EB%AC%B8%EA%B0%80%EB%AA%A8%EB%93%9C_%EA%B4%91%EA%B3%A0_%EC%86%94%EB%A3%A8%EC%85%98_%EC%86%8C%EA%B0%9C%EC%84%9C_%ED%86%B5%ED%95%A9.pdf)처럼 업로드 대상의 공식 양식을 기준으로 열을 고정한다.

| 검수 열 | AI가 찾을 것 | 사람이 다시 볼 것 |
|---|---|---|
| 상품 ID | 중복·공란 | 원본 상품관리번호 |
| 옵션 | 옵션명은 있는데 값이 없는 행 | 실제 판매 가능한 조합 |
| 가격·재고 | 음수, 숫자 형식, 비정상적으로 큰 값 | 원가·재고 시스템 |
| 배송·반품 | 배송비·제외 지역·반품 조건 누락 | 최신 정책 문서 |
| 필수 고지 | 카테고리별 빈칸 | 플랫폼 등록 양식 |

## 복사해서 쓰는 CSV 검수 프롬프트

ChatGPT는 CSV·XLSX를 분석하고 표와 차트를 만들 수 있다. Claude도 CSV를 지원하며, Gemini의 파일 업로드 형식과 한도는 계정·구독에 따라 달라진다. 같은 익명 샘플 10행으로 세 도구를 비교한 뒤 선택하면 된다. [ChatGPT 데이터 분석 안내](https://help.openai.com/ko-kr/articles/8437071-data-analysis-with-chatgpt), [Claude 파일 형식 안내](https://support.anthropic.com/en/articles/8241126-what-kinds-of-documents-can-i-upload-to-claude-ai), [Gemini 파일 업로드 안내](https://support.google.com/gemini/answer/14903178?hl=ko)에서 2026년 10월 23일 기준 지원 조건을 확인했다.

```text
첨부한 상품 카탈로그 CSV만 근거로 등록 전 검수표를 만들어라.
상품을 새로 만들거나 값을 추정하지 말고, 원본 행 번호를 반드시 남겨라.
열: 상품 ID | 상품명 | 옵션 상태 | 가격 상태 | 배송·반품 누락 | 필수 고지 누락 | 근거 열/값 | 조치
상태는 정상/확인 필요/차단으로만 표시하라.
확인 필요: 원문은 있지만 다른 열과 충돌하거나 형식이 애매한 경우
차단: 상품 ID·상품명·판매가·필수 옵션값이 없거나 중복된 경우
마지막에 전체 행 수, 정상 수, 확인 필요 수, 차단 수를 합계로 보여라.
```

결과를 받은 뒤 `차단` 행만 원본 CSV와 대조하고, `확인 필요`는 담당자에게 물을 질문으로 바꾼다. 예를 들어 옵션값이 `선택1`로만 들어간 행은 AI가 색상이나 사이즈를 추측할 일이 아니라 상품관리자에게 확인할 대상이다. CSV를 다시 저장할 때는 UTF-8, 열 이름, 줄바꿈, 쉼표 포함 문장을 확인한다.

## 무료와 유료의 경계

| 상황 | 선택 | 이유 |
|---|---|---|
| 월 1~2회, 30개 이하 | 무료 플랜 | 샘플 분할과 표 출력으로 충분 |
| 긴 상품 설명·이미지·여러 파일 반복 | 유료 검토 | 업로드·사용량·문맥 한도가 병목 |
| 여러 직원이 원본을 처리 | 회사 승인 환경 | 권한·보관·감사 정책이 필요 |

개인용 ChatGPT는 `Improve the model for everyone`을 끄면 새 대화를 모델 개선에 사용하지 않도록 설정할 수 있지만, 이것이 회사 원본 업로드 허가를 뜻하지는 않는다. OpenAI는 업무용 워크스페이스의 데이터 처리 조건이 개인 계정과 다르다고 안내한다. 이름, 전화번호, 주소, 주문번호, 내부 원가를 지운 샘플로 형식을 검증하고 실제 파일은 회사 정책을 따른다. [ChatGPT 데이터 제어 안내](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)

짧게 말하면 카탈로그 CSV에 AI를 붙일 때의 결과물은 상품 설명이 아니라 `정상 / 확인 필요 / 차단`으로 나뉜 행 목록이다. 샘플 10건에서 사람이 고친 행 수와 재검수 시간을 기록하고, 무료 한도 때문에 작업이 끊길 때만 유료 전환을 검토하면 된다.
