![SaaS 사용자 권한 CSV를 AI와 검토하는 체크리스트](../../../../assets/images/claude-agent-permission-checklist.png)
그림에서 볼 부분은 AI가 권한을 바꾸는 장면이 아니라, 사용자 CSV를 근거표로 바꾼 뒤 사람이 승인하는 흐름이다.

SaaS 관리자나 총무 담당자라면 ChatGPT·Claude·Gemini에 사용자 목록을 넣고 “정리해줘”라고 하기보다, 비활성 계정·외부 사용자·관리자 권한을 한 행씩 판정하게 만드는 편이 낫다. 공개 샘플이나 이름을 지운 CSV는 무료 플랜으로 형식을 시험할 수 있지만, 실제 직원 이메일과 접근 이력이 들어간 원본을 반복 검토하려면 회사 승인 계정과 보존정책을 먼저 확인해야 한다. AI가 계정을 삭제하거나 권한을 회수하게 하는 용도에는 맞지 않는다.

## 결과물은 권한 변경 명령이 아니라 검토 대기표다

CloudCannon은 access review를 조직 구성원, 로그인 방식, 최근 활동, 권한 그룹을 확인해 보안 감사의 증거로 만드는 CSV로 설명한다. 이 구조를 일반 SaaS에 적용하면 최종 산출물은 다음처럼 고정할 수 있다.

| 검토 열 | AI가 할 일 | 사람이 확인할 것 |
| --- | --- | --- |
| 사용자·계정 상태 | 활성, 초대 대기, 비활성 후보 분류 | 퇴사·휴직·외주 계약 상태 |
| 권한 그룹 | 관리자·편집자·읽기 전용으로 표준화 | 실제 직무에 필요한 최소 권한 |
| 최근 활동 | 마지막 로그인 날짜와 기준일의 차이 계산 | 로그 누락인지 실제 미사용인지 |
| 조치 | 유지·확인 필요·회수 후보로 표시 | 회수 승인자와 공식 처리 경로 |
| 근거 | 원본 행 번호와 판단 이유 기록 | 원본 관리자 화면과 대조 |

`조치=회수 후보`는 삭제 명령이 아니다. 계정·권한을 바꾸는 작업은 AI 결과를 복사하지 말고, 관리자가 원본 화면에서 직접 승인한다.

## 무료와 유료의 경계는 파일 개수보다 통제다

확인일은 2026년 10월 24일이다. 한도와 기능은 플랜·지역·워크스페이스 설정에 따라 바뀔 수 있다.

| 도구 | 무료로 시험할 범위 | 유료·회사 계정을 검토할 순간 | 확인한 제한·주의 |
| --- | --- | --- | --- |
| ChatGPT | 가상 사용자 20~50행 CSV로 열과 프롬프트 검증 | 실제 조직 파일, 반복 검토, 관리자 보존정책 필요 | 무료 사용자는 파일 업로드가 하루 3회로 제한될 수 있고, 개인 계정의 학습 사용 설정을 따로 확인해야 한다 |
| Claude | 익명화 CSV와 권한명 표준화 | 긴 사용자 목록과 팀 단위 프로젝트 운영 | 공식 안내는 파일당 30MB, 한 대화 최대 20개 파일을 안내하며 XLSX 분석은 계정 기능을 확인해야 한다 |
| Gemini | 샘플 CSV와 차트·누락 행 확인 | 여러 파일을 반복 참조하거나 Workspace 관리가 필요할 때 | 한 프롬프트에 최대 10개 파일을 안내하지만 파일 분석 한도는 시점과 플랜에 따라 달라진다 |

작은 조직이라면 무료 플랜에서 `판정 불가` 행이 얼마나 남는지만 세어도 된다. 3회 연속 검토에서 업로드 한도보다 관리자 승인·감사 로그가 병목이라면 유료 전환의 이유가 된다. 단순히 더 긴 답변이 필요하다는 이유만으로 결제하면 접근권한 문제는 해결되지 않는다.

## 바로 복사하는 CSV 검토 프롬프트

CSV에는 이름 대신 사번 해시나 임시 ID를 넣고, 실제 이메일 도메인과 고객 정보는 제거한다.

```text
너는 SaaS 접근권한 검토 보조자다. 첨부 CSV의 각 행을 원본 값만 사용해 검토하라.
오늘 기준일은 [YYYY-MM-DD]다. 추측하지 말고 정보가 없으면 판정 불가로 표시하라.
다음 열을 출력하라: 사용자 ID, 계정 상태, 권한 그룹, 마지막 활동일,
90일 이상 미활동 여부, 과다 권한 가능성, 조치(유지/확인 필요/회수 후보),
근거 열 번호, 사람이 확인할 질문.
회수 후보를 자동 확정하지 말고, 퇴사·휴직·외주 여부와 관리자 승인 경로를 질문하라.
행 수와 마지막 활동일의 최솟값·최댓값도 먼저 알려라.
```

첫 결과를 믿기 전에 행 수, 날짜 범위, 관리자 계정 수를 원본과 대조한다. 날짜가 비어 있는 사용자를 곧바로 미활동으로 분류하거나, 관리자라는 이유만으로 과다 권한으로 판정하는 것이 흔한 실패다. 권한 이름이 서비스마다 다르면 AI가 `owner`와 `admin`을 같은 등급으로 합칠 수도 있으므로, 회사의 권한 정의표를 함께 제공하고 모르는 값은 표준화하지 않게 해야 한다.

## 개인정보와 검수 체크리스트

- [ ] 이름·이메일·고객 ID를 가상 값으로 바꿨는가
- [ ] CSV 행 수와 마지막 활동일 범위를 원본과 비교했는가
- [ ] `판정 불가` 행을 별도로 남겼는가
- [ ] 회수 후보마다 승인자와 공식 처리 경로가 있는가
- [ ] AI 결과를 실제 권한 변경 화면에 자동 연결하지 않았는가

ChatGPT는 개인용 Free·Plus·Pro에서 모델 개선 사용 설정을 끌 수 있다고 안내하지만, 회사용 관리형 워크스페이스와는 데이터 통제가 다르다. Gemini도 프롬프트와 업로드 파일이 처리 대상임을 개인정보 허브에 설명한다. Claude·ChatGPT·Gemini 어느 쪽이든 “유료면 안전하다”로 단정하지 말고, 회사 정책·보존 기간·관리자 접근을 확인해야 한다.

짧게 말하면 무료 AI는 가상 CSV로 검토표 형식을 정하는 데 충분하다. 유료 전환은 사용자 수보다 실제 파일의 민감도, 반복량, 감사 기록, 관리자 통제가 병목일 때 판단한다. AI는 권한 심사관이 아니라 사람이 확인할 예외를 빠뜨리지 않게 하는 초안 작성자다.
