그림에서 볼 부분은 AI가 티켓을 해결하는 것이 아니라, 담당자가 먼저 볼 순서와 부족한 정보를 표로 만드는 흐름이다.

IT 헬프데스크에서 비슷한 로그인·권한·오류 문의를 하루 10~30건 처리한다면 ChatGPT·Claude·Gemini 중 하나를 무료로 시험해 **분류표와 추가 질문 목록**을 만드는 선택이 유리하다. 반대로 비밀번호, 인증 토큰, 사내 IP와 고객 식별정보를 원문 그대로 넣거나 AI가 계정 잠금 해제까지 하게 하려는 경우에는 이 방식이 맞지 않는다. 최종 조치와 우선순위 승인은 사람이 맡아야 한다.

## 요약보다 티켓 라우팅 표가 먼저다

“이 문의를 요약해줘”라고 하면 문장은 매끄럽지만 담당자와 처리 조건이 빠진다. 아래 열을 고정하면 결과를 헬프데스크 큐에 옮기기 쉽다.

| 항목 | AI가 할 일 | 사람이 확인할 것 |
|---|---|---|
| 유형 | 계정·권한·네트워크·장비·업무앱 중 1개 선택 | 팀의 실제 분류 체계와 일치하는지 |
| 긴급도 | 긴급/높음/보통/낮음과 근거 제시 | 장애 범위와 업무 중단 여부 |
| 담당 | 예상 팀 또는 담당 역할 | 실제 소유자와 당번 |
| 부족 정보 | 기기·시각·오류문구·영향 인원 질문 | 질문이 개인정보를 더 요구하지 않는지 |
| 다음 행동 | 승인된 런북 제목만 제안 | 실행 권한과 변경 승인 |

## 복사해서 쓰는 프롬프트

아래 프롬프트에 익명화한 티켓 10~20건과 사내 분류 기준만 붙인다.

```text
너는 IT 헬프데스크의 1차 분류 보조자다.
제공한 티켓과 아래 분류 기준만 사용하고, 원문에 없는 원인·심각도·해결책을 만들지 마라.

각 티켓을 다음 표로 반환하라.
티켓ID | 분류 1개 | 긴급도 | 근거 문장 | 예상 담당 역할 | 추가 질문 최대 2개 | 에스컬레이션 여부

규칙:
- 보안, 계정 탈취 의심, 여러 사용자의 업무 중단은 에스컬레이션 후보로 표시한다.
- 근거가 부족하면 긴급도를 “판단 보류”로 쓰고 필요한 증거를 적는다.
- 비밀번호, 토큰, 주민번호, 전화번호는 결과에 다시 쓰지 않는다.
- 해결 명령이나 계정 변경을 직접 지시하지 말고 승인된 런북 제목만 제안한다.
- 마지막에 분류별 건수와 “사람이 반드시 확인할 행”을 따로 정리한다.

분류 기준: [계정/권한, 네트워크, 장비, 업무앱, 보안 의심, 기타]
승인된 런북: [문서 제목과 링크]
티켓: [익명화한 원문]
```

## 무료와 유료의 경계

이 업무는 “어느 모델이 최고인가”보다 입력량과 관리 조건이 병목이다. 10건을 붙여 표 형식이 유지되는지부터 확인한다.

| 상황 | 무료 플랜으로 시작 | 유료·조직용 검토 |
|---|---|---|
| 주 1~2회, 익명 티켓 10건 | 가능 | 불필요 |
| 긴 로그·스크린샷을 매일 처리 | 업로드 제한 확인 | 사용량·파일 한도가 실제 병목일 때 |
| 팀 공용 분류 기준과 감사 기록 | 개인 채팅으로는 부족 | 회사 승인 워크스페이스 검토 |
| 자동 티켓 수정·발송 | 적용하지 않음 | 별도 연동과 실패 시 중지 절차 필요 |

확인 기준은 2026년 10월 28일이다. ChatGPT 개인 플랜은 파일·도구 사용에 제한이 있고, Claude Free는 사용량이 제한되며 Pro는 미국 기준 월 20달러로 안내된다. Gemini도 사용량이 프롬프트 복잡도와 기능에 따라 달라진다고 안내한다. 따라서 “무료는 몇 건”처럼 고정 숫자를 약속하기보다 실제 티켓 20건에서 중단 여부와 재작업 시간을 기록하는 편이 정확하다.

## 개인정보와 검수 체크리스트

ChatGPT는 개인 계정에서 모델 개선 설정을 끌 수 있지만, 설정 변경이 회사의 승인 절차를 대신하지 않는다. Gemini는 활동 설정과 사람 검토에 관한 별도 안내가 있고, Claude도 소비자 계정과 조직용 플랜의 데이터 조건이 다르다. 공통적으로 원문을 줄이는 것이 첫 방어선이다.

- [ ] 이름, 이메일, 사번, 전화번호, IP, 토큰을 가명 또는 마스킹했는가
- [ ] 티켓 ID와 근거 문장을 다시 원문과 대조했는가
- [ ] 긴급도와 담당자 판단에 근거가 붙었는가
- [ ] “판단 보류” 행을 사람이 먼저 확인했는가
- [ ] AI 결과가 계정 변경이나 자동 발송으로 이어지지 않았는가
- [ ] 20건 중 오분류, 누락 질문, 사람 수정 횟수를 기록했는가

티켓 분류는 무료 채팅으로도 시작할 수 있지만, 자동 해결은 다른 문제다. 무료로 가명 데이터 20건을 돌려 표의 정확성과 검수 시간을 측정하고, 업로드 한도·팀 권한·감사 로그가 실제 장애가 될 때만 유료 또는 조직용 환경으로 넘어가는 순서가 안전하다.
