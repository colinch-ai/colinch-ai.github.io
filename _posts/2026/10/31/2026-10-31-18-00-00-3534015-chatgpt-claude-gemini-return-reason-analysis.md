이 그림에서 볼 부분은 AI가 환불을 승인하는 장면이 아니라, 반품 기록을 상품별 문제·근거·확인할 개선안으로 바꾸는 흐름이다.

반품을 매주 20건 이상 처리하는 온라인 쇼핑몰 운영자라면 ChatGPT·Claude·Gemini 무료 기능으로 익명화한 CSV 30~100행을 시험하는 선택이 유리하다. 반품 건수가 적거나 사유 코드가 매번 다르면 AI보다 입력 양식을 고치는 일이 우선이다. 고객 이름·주소·주문번호가 들어간 원본을 개인 채팅에 올리거나 AI가 환불·재고 결정을 자동 실행하게 하려는 경우에는 이 방식이 맞지 않는다.

## 반품 분석에서 만들 결과물

Shopify는 상품 카테고리에 맞는 반품 사유를 제공하고, 분석 화면에서 사유별 추세를 확인할 수 있다고 안내한다([반품·교환 공식 안내](https://help.shopify.com/en/manual/orders/refunds-returns/exchanges)). ShopifyQL도 반품 수량을 상품별 사유로 묶어 보도록 예시를 제공한다([returns 스키마](https://shopify.dev/docs/api/shopifyql/2026-07/schemas/sales_revenue/returns)). AI에는 “인사이트”보다 아래 표를 요구하는 편이 검수하기 쉽다.

| 결과물 | 반드시 남길 값 | 사람이 확인할 부분 |
|---|---|---|
| 사유 집계 | SKU·사유·건수·반품률 | 분모가 주문 수인지 판매 수량인지 |
| 문제 묶음 | 사이즈·설명·품질·배송·단순 변심 | 한 건의 표현을 전체 원인으로 확대하지 않았는가 |
| 개선 후보 | 상세페이지 수정·검수 강화·포장 변경 | 실제 비용과 담당자 |
| 근거 | 원문 사유 ID·문장·기간 | CSV에 없는 원인을 만들지 않았는가 |

## 복사해서 쓰는 반품 CSV 프롬프트

CSV를 올리기 전에 고객명, 전화번호, 주소, 주문번호를 지우고 SKU도 필요하면 `상품A`처럼 바꾼다. `return_reason`, `sku`, `returned_qty`, `sold_qty`, `period`, `note` 열이 있다고 가정한 프롬프트다.

```text
너는 온라인 쇼핑몰 운영자의 데이터 검수 보조자다.
첨부한 반품 CSV에 있는 값만 사용해 아래 결과를 만들어라.

1. SKU·반품 사유별 반품 수량, 판매 수량, 반품률 표
2. 사유를 사이즈/상품 설명/품질/배송/단순 변심/기타로 묶은 표
3. 상품별 개선 후보 3개: 제안, 근거 행 또는 note, 예상 확인 방법
4. 데이터 누락·중복·분모 불명확 행

규칙:
- 반품률은 returned_qty / sold_qty로 계산하고 분모가 없으면 계산하지 마라.
- CSV에 없는 원인, 비용 절감액, 고객 감정을 추측하지 마라.
- 상관관계를 원인으로 단정하지 말고 “확인 필요”로 표시하라.
- 환불 승인, 재고 폐기, 공급사 책임 판단은 하지 마라.
- 모든 개선 후보에 원문 행 번호나 note를 붙여라.
```

반품률 숫자만 보고 “상품 품질이 나쁘다”고 결론 내리면 실패다. 같은 SKU라도 특정 사이즈만 문제가 있을 수 있고, 판매 수량이 0이거나 기간이 다르면 비율 비교가 무너진다. 개선안은 `사이즈표에 실측 추가 → 다음 2주 반품 사유 재집계`처럼 확인 방법까지 붙여야 실행 가능한 결과물이 된다.

## 무료와 유료를 가르는 기준

| 상황 | 무료로 시작 | 유료·회사 승인 환경 검토 |
|---|---|---|
| 데이터 | 익명화한 CSV 1개, 월 4회 이하 | 여러 기간·파일을 매주 비교 |
| 작업량 | 30~100행을 사람이 대조 | 긴 파일과 반복 참조가 병목 |
| 도구 차이 | ChatGPT·Claude·Gemini 중 익숙한 하나 | 팀 권한·공유·보존 정책이 필요 |
| 비용 판단 | 수정한 행 수와 검수 시간 기록 | 한 달 절약 시간이 구독료를 넘는지 계산 |

ChatGPT는 무료·유료 모두 파일 업로드를 지원하지만 플랜별 사용량 제한이 있고, 무료 사용자는 파일 업로드 제한이 별도로 적용된다([파일 업로드 FAQ](https://help.openai.com/en/articles/8555545-uploading-images-and-files-in-chatgpt)). Claude는 무료가 제한 사용, Pro가 월 20달러의 표준 사용량으로 안내되며 파일 크기와 메시지 길이도 한도에 영향을 준다([Claude 요금제](https://support.anthropic.com/en/articles/11049762-choosing-a-claude-ai-plan), [문서 업로드](https://support.anthropic.com/en/articles/8241126-what-kinds-of-documents-can-i-upload-to-claude-ai)). Gemini도 파일 업로드와 스프레드시트 차트 생성이 가능하지만, 더 높은 한도는 Google AI 요금제와 연결된다([Gemini 파일 분석](https://support.google.com/gemini/answer/14903178?hl=en-GB)). 가격보다 회사의 개인정보·업로드 정책을 확인해야 한다. OpenAI도 소비자 서비스와 Business·Enterprise의 데이터 사용 조건이 다르다고 설명한다([데이터 사용 FAQ](https://help.openai.com/en/articles/7039943-data-usage-for-consumer-services-far)).

## 발행 전 10분 검수표

- [ ] 반품률의 분모와 기간이 모든 행에서 같은가
- [ ] 고객 식별정보와 주문번호를 제거했는가
- [ ] 개선 후보마다 CSV 행 번호나 원문 메모가 있는가
- [ ] 판매 수량 0, 중복 행, 빈 사유를 따로 표시했는가
- [ ] AI의 원인 추정과 실제 확인된 사실을 분리했는가
- [ ] 상품 설명·사이즈표 수정 전 원본 상품 페이지를 사람이 확인했는가

반품 분석의 핵심은 AI가 “무엇이 문제인지” 단정하는 데 있지 않다. 운영자가 같은 사유를 같은 기준으로 모으고, 근거가 붙은 개선 후보를 만든 뒤, 다음 기간의 반품률로 다시 확인하는 데 있다. 작은 익명 CSV로 형식을 검증하고, 파일 한도·팀 권한·보존 정책이 실제 병목일 때만 유료 전환을 계산하면 된다.
