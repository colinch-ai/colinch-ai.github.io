이 그림에서 봐야 할 것은 제품 로고가 아니라, 구매 이유·무료 대안·반복 비용을 한 표에서 확인하는 흐름이다.

팀에서 SaaS 구매요청서를 자주 승인한다면 ChatGPT·Claude·Gemini 중 이미 쓰는 무료 도구 하나로 초안 검수를 시작하는 편이 낫다. 요청서가 짧고 가격만 확인하면 되는 경우엔 유료 구독이 필요 없다. 반대로 계약 조건, 기존 사용량, 보안 요구가 함께 들어오면 AI에게 승인 결정을 맡기지 말고 근거 누락을 찾는 보조 역할만 맡겨야 한다.

## 구매요청서에서 반복되는 누락

요청자는 보통 “업무 시간이 줄어든다”라고 쓰지만, 승인자는 다른 질문을 한다. 무료 요금제로 가능한지, 실제 사용자는 몇 명인지, 해지하면 데이터와 업무가 어떻게 되는지다.

| 검수 항목 | AI가 찾을 질문 | 사람이 확정할 값 |
|---|---|---|
| 업무 문제 | 어떤 반복 작업을 줄이나? | 현재 소요 시간과 담당자 |
| 무료 대안 | 기존 도구나 무료 플랜으로 가능한가? | 기능 제한과 파일·사용량 한도 |
| 유료 근거 | 돈을 내야만 생기는 결과물은 무엇인가? | 월 비용, 좌석 수, 갱신일 |
| 전환 비용 | 해지·이관 때 잃는 것이 있나? | 데이터 export, 대체 도구, 복구 담당자 |

가격표만 붙은 요청서는 보류하고, 이 표의 빈칸이 채워진 요청서만 결재선에 올리는 식으로 기준을 고정하면 도구 이름에 덜 끌려간다.

## 복사해서 쓰는 검수 프롬프트

실제 회사명, 고객명, 계약번호, 이메일은 지운 뒤 요청서와 공개된 요금제 정보만 넣는다. 아래 프롬프트는 승인이나 거절이 아니라 누락 보고서를 만들도록 제한한다.

```text
너는 SaaS 구매요청서 검수 담당자다.
아래 요청서를 다음 표로 다시 정리해라.
열: 업무 문제, 반복 빈도, 사용자 수, 무료 대안, 유료 전용 기능,
월/연간 비용, 해지·이관 위험, 확인이 필요한 질문, 근거 문장.

규칙:
1. 요청서에 없는 숫자는 추정하지 말고 '미기재'라고 써라.
2. 무료로 가능한 작업과 유료 기능을 분리해라.
3. 가격은 확인일과 통화를 붙이고, 모르면 확인 필요로 표시해라.
4. 마지막에 승인/보류를 결정하지 말고, 사람이 확인할 질문 5개만 제시해라.

[요청서]
...
```

ChatGPT·Claude·Gemini 모두 같은 입력을 넣고 결과를 합치는 것보다, 한 도구로 표를 만들고 다른 도구로 누락만 재검토하는 편이 관리하기 쉽다. 결과물은 “추천 도구”가 아니라 구매 담당자가 답할 질문 목록이어야 한다.

## 무료와 유료를 가르는 기준

무료 플랜은 월 1~2건의 짧은 요청, 공개 정보, 복사 가능한 표에 적합하다. 매주 여러 파일을 올리거나 팀원이 같은 양식을 반복 사용한다면 사용량 제한보다 작업 이력·권한·관리 기능이 비용 판단의 중심이 된다. 정확도가 자동으로 보장되는 것은 아니다.

| 상황 | 우선 선택 | 이유 |
|---|---|---|
| 공개 요금제 1개 비교 | 무료 ChatGPT·Claude·Gemini | 입력량이 작고 재사용 빈도가 낮다 |
| 매주 10건 이상 검수 | 현재 회사가 승인한 유료 도구 | 한도보다 기록·공유·관리 기준을 확인한다 |
| 개인정보·계약 초안 포함 | 개인 무료 채팅 보류 | 회사 정책과 업무용 데이터 약정을 먼저 확인한다 |

개인용 ChatGPT Free·Plus·Pro는 설정에 따라 대화가 모델 개선에 사용될 수 있고, Business·Enterprise·Edu는 별도 약정이 없으면 학습에 사용하지 않는다고 OpenAI가 안내한다([OpenAI 데이터 사용 안내](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)). Claude도 소비자용과 상업용 제품의 데이터 처리 설명이 다르다([Anthropic 개인정보 안내](https://privacy.anthropic.com/en/articles/10023555-how-do-you-use-personal-data-in-model-training)). Gemini는 일부 대화를 사람 검토자가 볼 수 있고 검토된 대화가 최대 3년 보관될 수 있다고 안내한다([Gemini Apps Privacy Hub](https://support.google.com/gemini/answer/13594961)). 그러므로 “유료 결제 = 기밀 보장”으로 해석하면 안 된다.

## 결재 전 5분 체크리스트

- [ ] 고객명·연락처·계약번호·API 키를 제거했나
- [ ] 무료 대안으로 할 수 없는 단계가 한 문장으로 적혔나
- [ ] 좌석 수, 결제 주기, 갱신일이 확인됐나
- [ ] 해지 시 파일 내보내기와 담당자가 정해졌나
- [ ] AI가 만든 비용·제한·보안 설명을 공식 페이지에서 다시 확인했나

AI가 만든 표는 결재 문서의 초안이지 증빙이 아니다. 특히 요금, 사용량 한도, 데이터 처리 조건은 2026년 11월 4일에 확인한 화면과 공식 약관을 함께 남겨야 한다. 이 방식이면 무료 도구를 써도 구매 판단에 필요한 결과물은 만들 수 있고, 유료 도구는 반복량과 관리 필요가 확인된 뒤 선택하게 된다.
