채용 담당자가 여러 면접관의 메모를 같은 형식으로 정리해야 한다면 ChatGPT·Claude·Gemini 무료 기능으로도 1차 평가표를 만들 수 있다. 다만 AI에게 합격자를 고르게 하면 안 된다. 지원자의 답변을 직무 역량별로 펼치고, 근거가 비어 있는 칸을 찾아내는 데만 쓰는 흐름이다. 주민등록번호, 연락처, 건강정보가 섞인 원본을 개인 계정에 그대로 올리는 경우에는 이 방법을 적용하지 않는 편이 낫다.

## 결과물은 ‘요약’이 아니라 근거표다

면접 메모를 그대로 요약하면 말이 매끄러워질 뿐 평가 기준은 통일되지 않는다. 아래처럼 질문, 답변 근거, 점수, 추가 확인 질문을 분리해야 사람이 다시 검수할 수 있다.

| 항목 | AI가 할 일 | 사람이 확인할 일 |
|---|---|---|
| 직무 역량 | 답변에서 근거 문장 추출 | 실제 직무와 관련 있는지 |
| 점수 | 사전 정의한 1~5점 기준 적용 | 점수가 근거와 맞는지 |
| 누락 | 답변에 없는 정보 표시 | 다음 면접 질문 결정 |
| 위험 신호 | 모순·추정·차별 표현 표시 | 사실 여부와 법무 기준 확인 |

## 복사해서 쓰는 프롬프트

메모를 붙여넣기 전에 이름, 연락처, 학교명처럼 불필요한 식별자를 가상 코드로 바꾼다. 점수 기준도 프롬프트 안에 고정한다.

```text
너는 채용 결정자가 아니라 면접 기록 정리 담당자다.
아래 면접 메모를 다음 JSON 표 형태로 정리해줘.

평가 항목: 문제 해결, 협업, 직무 지식
점수 기준: 1점=근거 없음, 3점=일부 근거 있음, 5점=구체적 행동과 결과가 있음
규칙:
- 메모에 없는 사실은 추측하지 말 것
- 각 점수마다 원문 근거를 짧게 인용할 것
- 개인적 인상, 말투, 나이, 성별, 출신지로 평가하지 말 것
- 판단이 어려우면 점수 대신 '추가 확인'으로 표시할 것
- 마지막에 면접관이 다시 물을 질문 3개를 만들 것

출력 열: 평가 항목 | 점수 | 근거 | 불확실성 | 추가 질문
면접 메모:
[여기에 비식별화한 메모]
```

## 무료와 유료의 경계

2026년 11월 5일 공식 안내를 기준으로 확인한 범위는 아래와 같다. 세 서비스 모두 계정·지역·워크스페이스에 따라 한도가 달라질 수 있으므로, 표의 ‘유료’는 품질 보장이 아니라 반복 사용 여유를 뜻한다.

| 상황 | 무료로 시작 | 유료·관리형을 검토할 때 |
|---|---|---|
| 주 1~2건, 짧은 메모 | 세 도구 중 하나로 비교 | 굳이 결제하지 않음 |
| 여러 파일·긴 메모를 매주 처리 | 파일을 합쳐 한 번에 검수 | 업로드·메시지 한도 확인 |
| 팀이 같은 평가표를 사용 | 템플릿을 문서로 공유 | 권한·보존·감사 로그가 있는 업무용 검토 |
| 민감한 지원자 정보 포함 | 비식별화 후 최소 정보만 사용 | 개인 플랜보다 조직 정책 우선 |

ChatGPT는 무료와 유료 모두 파일 업로드가 가능하지만 플랜별 사용량 제한이 있다. 개인 워크스페이스에서는 `Settings → Data controls → Improve the model for everyone`을 끌 수 있고, 관리형 워크스페이스는 기본 정책이 다르다. Claude는 무료 계정도 파일 생성·분석 기능을 제공하며 파일당 최대 30MB라고 안내한다. Gemini는 업로드 파일 분석이 가능하지만 더 높은 한도는 Google AI 요금제로 늘릴 수 있고, Keep Activity 설정에 따라 활동이 서비스 개선에 사용될 수 있다. 공식 문서는 [ChatGPT 파일 업로드 안내](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt), [ChatGPT 데이터 제어](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt), [Claude 파일 작업 안내](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude), [Gemini 파일 업로드 안내](https://support.google.com/gemini/answer/14903178?hl=en), [Gemini 개인정보 보호 허브](https://support.google.com/gemini/answer/13594961?hl=en)다.

## 발행 전 검수 체크리스트

- 원문에 없는 경력·성격을 AI가 추가하지 않았는가
- 모든 점수에 면접 메모의 근거가 붙어 있는가
- 평가 항목이 지원자마다 동일한가
- 민감정보와 불필요한 식별자를 제거했는가
- AI 표를 그대로 합격·불합격 근거로 쓰지 않았는가

미국 공공기관 OPM도 구조화 면접 기록은 직무 관련 질문에 대한 답변과 일관된 점수 방법을 기록하는 용도라고 설명한다. Greenhouse 역시 AI 면접 메모의 결과가 요약과 구조화된 노트이며, 전형 진행·탈락 결정은 채용 담당자와 관리자가 해야 한다고 안내한다. 따라서 이 작업의 검증 가능한 결과물은 ‘추천 후보’가 아니라, 같은 기준으로 다시 읽을 수 있는 평가표다.
