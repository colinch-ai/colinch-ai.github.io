그림에서 볼 것은 예쁜 화면이 아니라 `초안 문장 → 확인할 주장 → 원문 출처 → 사람 승인`의 순서다.

매주 블로그·뉴스레터·상품 설명 초안을 검토하는 콘텐츠 담당자라면 ChatGPT·Claude·Gemini에 초안과 공개 출처를 함께 주고, **주장-출처 검수표**부터 만들게 하는 선택이 유리하다. 반대로 법률·의료·금융처럼 한 문장의 오류가 바로 손실로 이어지는 글을 AI 결과만 보고 게시하는 방식에는 적용되지 않는다.

## AI에게 맡길 일과 맡기지 않을 일

OpenAI는 ChatGPT를 최종 출처가 아닌 초안 도구로 쓰고 숫자·날짜·인용·주요 주장을 직접 확인하라고 안내한다. 검색 기능이 출처 링크를 보여줘도 링크를 열어 원문과 대조해야 한다. 그러므로 AI의 역할은 진위를 선언하는 것이 아니라 검토 대상을 빠짐없이 쪼개는 데 둔다.

| 작업 | AI가 할 일 | 사람이 확인할 일 |
|---|---|---|
| 주장 추출 | 문장을 사실 주장 단위로 분리 | 문장 경계와 누락 여부 |
| 출처 연결 | 제공된 URL과 관련 문장 매칭 | 원문이 실제로 같은 말을 하는지 |
| 위험 표시 | 숫자·날짜·비교급·인용에 표시 | 게시·보류·수정 결정 |

## 복사해서 쓰는 검수 프롬프트

초안 전체를 무작정 “팩트체크해줘”라고 보내지 말고, 기준일과 허용 출처를 고정한다.

```text
너는 콘텐츠 편집 보조자다. 아래 초안의 사실 주장을 한 문장 단위로 분리해 표로 정리해라.

기준일: 2026-11-06
허용 출처: 정부·공공기관·제품 공식 문서·원문 연구·작성자가 제공한 URL

열은 [번호, 초안 주장, 주장 유형, 확인할 핵심어, 출처 URL, 원문 근거, 상태, 수정안]으로 만들어라.
상태는 [확인, 일부 확인, 확인 불가, 충돌] 중 하나만 사용해라.
출처를 열 수 없거나 원문에 같은 근거가 없으면 확인 불가로 표시해라.
숫자·날짜·가격·최상급 표현은 별도 경고를 붙여라.
초안과 출처에 없는 사실, URL, 인용문을 만들지 마라. 마지막에 사람이 직접 열어볼 링크만 따로 모아라.

[여기에 초안과 출처 목록 붙여넣기]
```

결과에서 `확인`이라는 단어보다 `원문 근거`가 비어 있지 않은지를 본다. URL만 그럴듯하게 생성하거나, 한 출처의 조건을 문장 전체의 근거처럼 확장하면 실패다. 그 행은 삭제하거나 원문을 직접 확인한 뒤 다시 쓴다.

## 무료와 유료의 경계

아래는 2026년 11월 6일 각 공식 안내를 확인한 기준이다. 한도와 기능은 계정·지역·시점에 따라 바뀔 수 있다.

| 상황 | 무료로 시작 | 유료·업무용 검토 시점 |
|---|---|---|
| 주 1~2회, 짧은 초안 | 주장 10~20개와 URL 몇 개 | 굳이 결제하지 않아도 됨 |
| 매일 여러 초안 | 파일·검색·메시지 한도에 걸리면 작업을 나눔 | 반복 한도와 긴 문맥이 실제 병목일 때 |
| 팀 공동 검수 | 결과표를 수동으로 공유 | 권한·보존·관리자 통제가 필요할 때 |

ChatGPT 무료 계정은 파일 업로드와 데이터 분석에 별도 한도가 있고, Claude 무료 계정도 사용량이 제한된다. Gemini는 파일 업로드·분석의 롤링 한도가 있으며 더 많은 사용량이나 큰 문맥이 필요하면 상위 요금제를 안내한다. 세 서비스 모두 민감한 원문을 개인 계정에 올려도 된다는 뜻은 아니다. 이름·이메일·계약번호·고객 식별자를 지우고, 조직 자료는 회사 승인 환경을 우선한다.

## 게시 전 5분 체크리스트

- [ ] 숫자·날짜·가격·인용문마다 원문 URL이 있다.
- [ ] URL을 직접 열어 주장과 같은 범위인지 확인했다.
- [ ] `최초`, `유일`, `보장` 같은 표현의 조건을 확인했다.
- [ ] AI가 찾지 못한 항목을 `확인 불가`로 남겼다.
- [ ] 최종 게시자는 검수표의 상태와 수정 이력을 승인했다.

무료 계정으로도 이 표를 한 주간 만들어 보면 결제 판단에 필요한 자료가 생긴다. 유료 전환의 근거는 “더 똑똑해 보인다”가 아니라, 실제로 반복 한도·공유 권한·보존 정책 때문에 사람이 낭비한 시간이어야 한다.
