반복 문의가 하루 10건 안팎인 CS 담당자라면 ChatGPT나 Claude 무료 플랜으로 가린 문의 10건을 먼저 시험해도 된다. 다만 결제·환불·계약처럼 잘못 답하면 비용이 생기는 문의를 자동 발송하려는 경우에는 이 글의 방식이 맞지 않는다. 목표는 AI가 고객 응대를 끝내는 것이 아니라, 근거가 붙은 답변 초안과 사람의 확인 기록을 남기는 것이다.

## 무료와 유료를 가르는 기준

| 항목 | 무료로 시작할 조건 | 유료·업무용 환경을 검토할 조건 |
|---|---|---|
| 작업량 | 하루 10건 이하, 한 번에 짧은 문의 | 여러 상담원이 매일 반복 처리 |
| 자료 | 익명화한 FAQ 5개 이하 | 정책 문서·매뉴얼을 계속 참조 |
| 결과 | 답변 초안과 근거 문장 | 권한, 공유, 감사 로그가 필요 |
| 개인정보 | 이름·전화·주문번호를 제거 | 원본을 조직 정책 안에서 다뤄야 함 |

확인 날짜는 2026년 11월 12일이다. OpenAI는 무료 사용자 파일 업로드를 하루 3개로 제한한다고 안내하며, ChatGPT Business의 업무 데이터는 기본적으로 모델 학습에 사용하지 않는다고 설명한다. 개인 워크스페이스는 설정에서 학습 사용을 끌 수 있지만, 이것이 회사 승인 환경을 대신하지는 않는다. Claude는 무료 계정도 프로젝트를 만들 수 있지만 최대 5개이며, 유료 플랜의 프로젝트 지식 확장(RAG)과 사용량은 별도 조건이다. Claude의 유료 플랜도 세션·주간 한도가 있으므로 “유료면 무제한”으로 계산하면 안 된다.

## 복사해서 쓰는 답변 초안 프롬프트

아래에서 `[문의]`에는 개인정보를 지운 가상 문의를 넣는다. 실제 고객 데이터로 테스트하지 않는다는 전제가 중요하다.

```text
너는 CS 답변 초안 검수 보조자다.
아래 FAQ와 문의만 사용해 답변 초안을 작성해라.

규칙:
1. FAQ에 없는 정책·가격·기한은 추측하지 말고 "확인 필요"라고 표시한다.
2. 답변마다 근거가 된 FAQ 번호를 붙인다.
3. 환불, 개인정보, 법적 분쟁, 계정 잠금은 상담원 확인 필요로 분류한다.
4. 고객에게 보낼 문장과 내부 검수 메모를 분리한다.
5. 이름, 전화번호, 주문번호 같은 식별정보는 출력하지 않는다.

[FAQ]
F-01. 배송 지연 시 영업일 기준 3일 뒤 문의 접수
F-02. 미개봉 상품은 수령 후 7일 이내 반품 신청

[문의]
가상 고객이 배송이 늦어 환불 가능한지 물었다.

출력 형식:
- 분류:
- 고객 발송용 초안:
- 근거 FAQ:
- 확인 필요 항목:
```

핵심은 모델 이름보다 출력 형식이다. 근거 FAQ가 비어 있거나, 답변에 없는 날짜가 생기면 바로 실패로 기록한다. ChatGPT는 임시 대화에서 기록·메모리 생성을 줄이고 모델 개선에 사용하지 않는다고 안내하지만 안전 목적의 보관 가능 기간은 별도로 남아 있다. 따라서 임시 대화도 민감한 원문을 넣어도 된다는 뜻은 아니다.

## 10건으로 유료 전환을 판단하는 검수표

- [ ] 개인정보를 지운 가상 문의 10건을 준비했다.
- [ ] 정답 정책과 답변의 근거 번호를 사람이 대조했다.
- [ ] `확인 필요`를 누락한 건수를 기록했다.
- [ ] 초안 수정 시간과 처음부터 작성한 시간을 같은 조건에서 적었다.
- [ ] 10건 중 2건 이상에서 정책 오류가 났다면 자동 발송을 중단했다.
- [ ] 팀 공유·권한·보존 정책이 필요할 때만 유료 또는 업무용 플랜을 검토했다.

가상 사례로 10건 중 8건이 초안으로 쓸 만해도, 나머지 2건이 환불이나 개인정보 문의라면 정확도 평균만 보고 도입하면 안 된다. 유료 전환 기준은 “더 똑똑해 보이는 답변”이 아니라 검수 시간 감소, 정책 근거 유지, 데이터 처리 승인 여부다. 이 세 가지 중 하나라도 확인되지 않으면 무료 테스트 단계에 머무는 편이 안전하다.
