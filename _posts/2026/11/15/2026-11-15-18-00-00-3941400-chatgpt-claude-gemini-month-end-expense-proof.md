재무·총무 담당자가 매달 영수증과 지출 내역을 모으는 업무라면 ChatGPT·Claude·Gemini 무료 기능으로 **누락표와 증빙 요청 메일 초안**을 만드는 선택이 유리하다. 반대로 AI에게 계정과목을 확정하거나 지급 승인을 맡기려는 경우에는 적용 대상이 아니다. AI가 할 일은 회계 판단이 아니라, 이미 있는 목록에서 빠진 파일·날짜·금액·담당자를 같은 형식으로 드러내는 것이다.

## 월말 마감에서 AI가 맡을 일

실무에서 시간이 걸리는 부분은 합계를 내는 일보다 “어떤 사람이 어떤 증빙을 언제까지 내야 하는가”를 다시 찾는 과정이다. 지출 CSV와 제출 파일 목록을 익명화해 넣고 아래 열을 고정하면 결과를 사람이 재검토할 수 있다.

| 검수 열 | AI가 찾을 단서 | 사람이 확인할 원문 |
|---|---|---|
| 대상자·부서 | 담당자 ID, 비용센터 | 경비 시스템 |
| 거래일·금액 | 날짜, 공급가액, 부가세 | 영수증·카드 내역 |
| 증빙 상태 | 제출·누락·판독 불가 | 첨부 파일 목록 |
| 예외 사유 | 취소, 개인 결제, 중복 | 승인 메모·정책 |
| 다음 행동 | 재제출, 설명 요청, 보류 | 사내 마감 규칙 |

그림에서 봐야 할 점은 합계보다 `누락 상태 → 담당자 → 다음 행동`이 한 줄로 이어지는 구조다.

## 복사해서 쓰는 프롬프트

파일명과 직원 이름은 `직원 A`, `부서 1`처럼 바꾼 뒤 사용한다.

```text
너는 월말 경비 증빙 검수 보조자다.
첨부한 지출 목록과 제출 파일 목록만 사용해 아래 표를 만들어라.
열: 대상자ID | 부서 | 거래일 | 금액 | 증빙상태 | 근거 파일명 | 다음 행동
원문에 없는 값은 추측하지 말고 '확인 필요'로 표시하라.
증빙상태는 제출, 누락, 판독 불가, 중복 중 하나만 사용하라.
마지막에 누락·판독 불가·중복 행만 모아 담당자별 요청 메일 초안을 작성하라.
```

결과를 받은 뒤에는 표의 `근거 파일명`을 실제 폴더에서 열고 금액과 날짜를 대조한다. 숫자 합계는 스프레드시트 수식이나 계산기로 별도 검산한다. AI가 “누락 없음”이라고 말해도 파일 목록 자체가 최신인지 확인하지 않으면 검수는 끝난 것이 아니다.

## 무료와 유료의 경계

| 상황 | 무료로 시작 | 유료·조직용 검토 |
|---|---|---|
| 월 1회, 소량 자료 | 비식별 CSV와 파일 목록 1회 처리 | 구독 불필요 |
| 파일이 많고 재처리 반복 | 업로드 한도에 걸리면 분할 | 긴 문서·반복 작업 한도 확인 |
| 여러 담당자가 함께 사용 | 결과표를 수동 공유 | 권한·보관·관리자 기능 비교 |
| 민감한 원본 포함 | 개인 계정에 업로드하지 않음 | 회사 승인 환경과 정책 확인 |

OpenAI는 파일 업로드가 무료·유료 요금제에 제공되지만 무료 사용자는 업로드 횟수 제한이 있을 수 있다고 안내한다. Gemini도 파일 분석에 기간별 한도가 있고, 더 많은 파일은 상위 요금제에서 제공될 수 있다고 안내한다. 한두 번의 비식별 샘플이면 결제보다 스프레드시트 양식을 고정하는 편이 낫다.

개인 계정에 원본을 올리는 일은 별도 판단이 필요하다. ChatGPT는 개인 계정에서 모델 개선 설정을 끌 수 있고, 임시 채팅은 기록과 모델 개선 사용 방식이 다르다. Claude 소비자 제품도 학습 사용 여부를 선택하는 정책이 있으므로 계정 설정을 확인해야 한다. 회사 정책이 더 엄격하면 무료·유료 여부와 관계없이 업로드하지 않는 것이 기준이다.

## 마감 전 사람 검수 체크리스트

- [ ] 주민등록번호, 계좌번호, 카드번호, 고객 정보가 제거됐나
- [ ] 지출 목록의 기준일과 제출 파일 목록의 기준일이 같은가
- [ ] 금액·부가세·통화 단위를 원문과 대조했나
- [ ] `확인 필요`가 임의의 계정과목이나 사유로 바뀌지 않았나
- [ ] 요청 메일을 자동 발송하지 않고 담당자가 승인했나
- [ ] 결과표의 보관 기간과 삭제 위치가 정해졌나

AI가 만든 표는 회계 장부가 아니라 재촉할 대상을 찾는 작업지다. 실제 마감 자료에 적용하기 전 가상 데이터 10행으로 누락·중복·판독 불가 세 가지 사례가 모두 표시되는지 확인하면 된다. 반복 건수가 적다면 무료 도구를 유지하고, 업로드 한도보다 권한·보관·감사 기록이 병목이 될 때 조직용 플랜을 비교하는 순서가 안전하다.
