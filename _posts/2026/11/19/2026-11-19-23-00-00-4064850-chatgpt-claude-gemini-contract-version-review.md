이 그림에서 볼 것은 계약서 자체가 아니라, 두 버전의 차이를 표로 남겨 사람이 승인하는 검수 흐름이다.

구매·계약 담당자가 같은 계약서의 v1과 v2를 반복해서 대조한다면 ChatGPT·Claude·Gemini로 **변경 문구, 실무 영향, 담당자 확인 질문**까지 초안화할 수 있다. 다만 법률 판단이나 승인까지 맡기는 용도는 아니다. 실제 계약 원문을 외부 개인 계정에 올릴 수 없는 조직이라면 비식별 샘플로 형식만 시험하고, 승인된 업무용 환경에서만 본문을 다뤄야 한다.

## AI에게 바로 맡기면 놓치는 것

“두 계약서의 차이를 요약해줘”라고 하면 문장이 달라진 사실과 중요한 변경을 구분하지 못한다. 금액·기간·책임 주체·삭제 조항을 별도 열로 고정해야 사람이 원문을 다시 찾을 수 있다.

| 확인 대상 | AI가 만들 결과물 | 사람이 다시 볼 지점 |
|---|---|---|
| 이용료·할인·정산 | v1/v2 숫자와 변화 방향 | 단위, 부가세, 적용 시작일 |
| SLA·납기·통지 | 의무와 기한 비교 | 누가 언제 통지하는지 |
| 해지·갱신 | 조건 변경과 확인 질문 | 자동 갱신, 위약금, 예외 |
| 개인정보·보안 | 데이터 처리 관련 변경 | 부속합의서·보안서 우선순위 |

## 복사해서 쓰는 비교 프롬프트

두 파일을 올리기 전에 회사명, 담당자 이름, 계좌, 고객 식별자, 미공개 단가를 `[회사A]`, `[담당자1]`처럼 바꾼다. 기준본과 수정본의 이름도 프롬프트 안에서 고정한다.

```text
너는 구매 담당자의 계약 변경 검수 보조자다.
첨부한 계약서 v1(기준본)과 v2(수정본)만 근거로 아래 표를 작성하라.

열: 조항 번호/제목 | v1 원문 | v2 원문 | 변경 유형(추가·삭제·수정·변경 없음)
| 실무 영향(금액·기간·의무·데이터·해지 중 해당 항목) | 확인 질문

규칙:
1. 두 파일에 없는 내용은 추론하지 말고 “원문에 없음”이라고 쓴다.
2. 숫자, 날짜, 비율, 주체, 부정어(않다/제외)를 그대로 인용한다.
3. 영향은 법률 결론이 아니라 담당자가 확인할 업무 질문으로 쓴다.
4. 변경이 없는 조항은 표에서 제외하되, 비교 범위를 끝에 적는다.
5. 끝에 금액·기간·책임·개인정보·해지 순서의 5분 검수 목록을 만든다.
```

출력된 표는 원문 인용이 실제 파일과 같은지 확인한다. “30일 이내”가 “30일 전”으로 바뀌었는지처럼 방향이 뒤집힌 표현은 AI 요약보다 원문 검색이 우선이다. OpenAI도 금융 서비스용 공식 프롬프트 예시에서 계약 버전별 문구와 상업·위험·운영 영향을 표로 나누는 방식을 제시한다([계약 세부사항 비교 예시](https://cdn.openai.com/pdf/b96a6047-53b2-43bd-85b9-44885cf4007a%20/chatgpt-enterprise-prompt-pack-for-financial-services.pdf)).

## 무료로 시험할 때와 유료를 검토할 때

| 상황 | 선택 | 이유와 제한 |
|---|---|---|
| 가상 계약서 2개, 월 1~2회 | 무료 플랜부터 | 프롬프트와 표 구조를 검증하기 충분하다 |
| 긴 PDF 여러 개를 매주 비교 | 파일 분석이 되는 플랜 | 업로드·문맥·사용량 한도와 재처리 비용을 확인한다 |
| 팀이 같은 기준으로 검수 | 승인된 업무용 환경 | 권한, 보존, 감사 기록이 개인 구독보다 중요하다 |
| 서명본·부속합의서까지 법적 판단 | AI만으로 처리하지 않음 | 법무 담당자와 원문·우선순위를 확인한다 |

Claude는 PDF·DOCX·CSV 등 파일 형식과 채팅당 파일 제한을 안내하지만 계정과 시점에 따라 달라질 수 있다([Anthropic 문서 업로드 안내](https://support.anthropic.com/en/articles/8241126-what-kinds-of-documents-can-i-upload-to-claude-ai)). Gemini는 업로드 한도가 있고 더 높은 한도는 Google AI 플랜에서 제공될 수 있다고 안내한다([Gemini 파일 분석 안내](https://support.google.com/gemini/answer/14903178)). ChatGPT 개인용 서비스는 설정에 따라 프롬프트와 파일이 모델 개선에 사용될 수 있고, Business·Enterprise는 기본 데이터 정책이 다르다([OpenAI 데이터 사용 FAQ](https://help.openai.com/en/articles/7039943-chatgpt-data-usage-faq)). 따라서 **유료 결제 = 계약 기밀 보장**으로 해석하면 안 된다.

## 5분 최종 검수표

- [ ] v1·v2의 기준일과 파일명이 맞는가
- [ ] 금액·통화·세금·기간의 숫자를 원문에서 재확인했는가
- [ ] 의무의 주체와 통지 방향이 바뀌지 않았는가
- [ ] 삭제된 조항이 별도 부속서로 이동한 것은 아닌가
- [ ] AI가 쓴 영향은 법률 결론이 아니라 담당자 질문으로 남았는가
- [ ] 개인정보·영업비밀을 제거했으며 회사의 업로드 승인을 받았는가

계약 버전 비교에서 AI의 역할은 “안전하다” 또는 “불리하다”를 판정하는 데 있지 않다. 변경된 원문을 빠르게 표로 모으고, 사람이 다시 확인할 숫자와 질문을 남기는 데 있다. 비식별 가상 파일로 정확한 표 형식을 고정한 뒤 실제 문서는 조직의 보안 정책과 법무 검토 절차 안에서 처리하는 편이 비용과 복구 위험을 함께 줄인다.
